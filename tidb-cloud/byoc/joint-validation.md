# TiDB Cloud BYOC 共同検証

最終フェーズでは、環境が安定しており、安全で、かつ完全に可観測であることを確認します。TiDB Cloud チームは、お客様と連携して以下のチェックを実施します。

## 検証チェックリスト {#validation-checklist}

| カテゴリ | 検証項目 | 担当者 |
| :---- | :---- | :---- |
| **接続性** | SQL エンドポイント: アプリケーションサーバーからプライベートおよびパブリックの両方の SQL エンドポイントへの接続性を確認します。 | お客様 |
| **接続性** | セキュアトンネル（任意）: 踏み台ホスト経由の VPN 接続が安定していることを確認します。 | TiDB Cloud |
| **可観測性** | メトリクス: Grafana および Prometheus でシステムメトリクスが正しく表示されていることを確認します。 | TiDB Cloud |
| **可観測性** | ロギング: ログが収集されていることを確認します。 | TiDB Cloud |
| **セキュリティ** | 監査: AWS CloudTrail が踏み台ホストへのアクセス試行をアクティブに記録していることを確認します。 | お客様 |
| **アラート** | テストアラート: テストアラートをトリガーして、通知配信システムが機能していることを確認します。 | 共同 |

すべての検証項目が **Pass** とマークされたら、次の状態になります。

1. このデプロイは正式に **Complete** と見なされます。
2. データ移行またはアプリケーション統合に進むことができます。

## 次のステップ {#what-s-next}

{{{ .byoc }}} デプロイの検証が完了したら、アプリケーションをインスタンスに接続し、データを移行するか、監視、バックアップ、セキュリティなどの運用機能の設定を続けることができます。デプロイ時に付与される権限をさらに削減するには、[TiDB Cloud BYOC のセキュリティ強化](/tidb-cloud/byoc/security-hardening.md) を参照してください。
