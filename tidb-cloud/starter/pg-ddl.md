# PostgreSQL DDL

与 PostgreSQL 兼容的 {{{ .starter }}} 支持常见的 PostgreSQL 数据定义语言（DDL）语句，用于创建和管理数据库对象。

## 创建表 {#create-a-table}

使用 `CREATE TABLE` 创建表：

```sql
CREATE TABLE users (
    id BIGSERIAL PRIMARY KEY,
    name TEXT NOT NULL,
    email TEXT UNIQUE,
    active BOOLEAN DEFAULT true,
    created_at TIMESTAMPTZ DEFAULT now()
);
```

支持以下常见约束和列属性：

- `NOT NULL`
- `DEFAULT`
- `PRIMARY KEY`
- `UNIQUE`
- `REFERENCES` 和 `FOREIGN KEY`
- `CHECK`

例如：

```sql
CREATE TABLE orders (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT NOT NULL REFERENCES users(id),
    amount NUMERIC(10, 2) CHECK (amount >= 0)
);
```

外键支持以下常见的 `ON DELETE` 和 `ON UPDATE` 操作：

- `CASCADE`
- `SET NULL`
- `SET DEFAULT`
- `RESTRICT`
- `NO ACTION`

### 通过查询创建表 {#create-a-table-from-a-query}

支持 `CREATE TABLE ... AS SELECT` 和 `SELECT ... INTO`：

```sql
CREATE TABLE active_users_snapshot AS
SELECT id, name, email
FROM users
WHERE active = true;
```

```sql
SELECT id, name
INTO user_names
FROM users;
```

> **Note:**
>
> 使用 `CREATE TABLE ... AS SELECT` 或 `SELECT ... INTO` 创建的表会额外包含一个 `_rowid` 主键列。有关其他 DDL 兼容性差异，请参见 [PostgreSQL 兼容性](/tidb-cloud/starter/postgresql-compatibility.md)。

### 标识列 {#identity-columns}

支持 `GENERATED ALWAYS AS IDENTITY` 和 `GENERATED BY DEFAULT AS IDENTITY`：

```sql
CREATE TABLE items (
    id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    name TEXT NOT NULL
);
```

```sql
CREATE TABLE tasks (
    id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title TEXT NOT NULL
);
```

标识列在序列选项方面存在兼容性差异，例如自定义起始值和步长。如果你需要自定义起始值或步长，请使用显式序列。

例如：

```sql
CREATE SEQUENCE order_seq
START WITH 1000
INCREMENT BY 5;

CREATE TABLE sequence_orders (
    id BIGINT PRIMARY KEY DEFAULT nextval('order_seq'),
    description TEXT
);
```

### 生成列 {#generated-columns}

```sql
CREATE TABLE products (
    id BIGSERIAL PRIMARY KEY,
    price NUMERIC,
    tax NUMERIC,
    total NUMERIC GENERATED ALWAYS AS (price + tax) STORED
);
```

## 创建索引 {#create-an-index}

B-tree 是默认的索引访问方法：

```sql
CREATE INDEX idx_users_name
ON users (name);
```

创建唯一索引：

```sql
CREATE UNIQUE INDEX idx_users_email
ON users (email);
```

支持表达式索引：

```sql
CREATE INDEX idx_users_lower_email
ON users (lower(email));
```

支持部分索引：

```sql
CREATE INDEX idx_active_users
ON users (id)
WHERE active = true;
```

也支持 `CREATE INDEX CONCURRENTLY`：

```sql
CREATE INDEX CONCURRENTLY idx_users_created_at
ON users (created_at);
```

支持以下索引访问方法：

| 索引方法 | 典型用途 |
| --- | --- |
| B-tree | 等值查询、范围查询和有序查找 |
| GIN | JSONB、数组和全文搜索 |
| HNSW | 近似最近邻向量搜索 |

有关 HNSW 索引的要求，请参见 [向量搜索](/tidb-cloud/starter/pg-vector-search.md)。

有关不支持的 PostgreSQL 索引访问方法，请参见 [PostgreSQL 兼容性](/tidb-cloud/starter/postgresql-compatibility.md)。

### GIN 索引示例 {#gin-index-example}

在 `JSONB` 列上创建 GIN 索引：

```sql
CREATE TABLE documents (
    id BIGSERIAL PRIMARY KEY,
    metadata JSONB
);

CREATE INDEX idx_documents_metadata
ON documents
USING GIN (metadata);
```

然后查询 JSONB 包含关系：

```sql
SELECT *
FROM documents
WHERE metadata @> '{"type":"pdf"}';
```

GIN 索引也可用于全文搜索。更多信息，请参见 [全文搜索](/tidb-cloud/starter/pg-full-text-search.md)。

## 创建和管理视图 {#create-and-manage-views}

创建视图：

```sql
CREATE VIEW active_users AS
SELECT id, name, email
FROM users
WHERE active = true;
```

替换现有视图：

```sql
CREATE OR REPLACE VIEW active_users AS
SELECT id, name, email, created_at
FROM users
WHERE active = true;
```

`CREATE OR REPLACE VIEW` 可以追加列，但不能删除或重命名现有视图列。

创建并刷新物化视图：

```sql
CREATE MATERIALIZED VIEW user_summary AS
SELECT active, count(*) AS user_count
FROM users
GROUP BY active;
```

```sql
REFRESH MATERIALIZED VIEW user_summary;
```

## 修改表 {#alter-a-table}

支持以下常见的 `ALTER TABLE` 操作：

| 操作 | 示例 |
| --- | --- |
| 添加列 | `ALTER TABLE users ADD COLUMN phone TEXT;` |
| 删除列 | `ALTER TABLE users DROP COLUMN phone;` |
| 重命名列 | `ALTER TABLE users RENAME COLUMN name TO display_name;` |
| 重命名表 | `ALTER TABLE users RENAME TO app_users;` |
| 设置默认值 | `ALTER TABLE users ALTER COLUMN active SET DEFAULT true;` |
| 删除默认值 | `ALTER TABLE users ALTER COLUMN active DROP DEFAULT;` |
| 设置 `NOT NULL` | `ALTER TABLE users ALTER COLUMN email SET NOT NULL;` |
| 删除 `NOT NULL` | `ALTER TABLE users ALTER COLUMN email DROP NOT NULL;` |
| 更改类型 | `ALTER TABLE users ALTER COLUMN name TYPE VARCHAR(255);` |
| 添加约束 | `ALTER TABLE users ADD CONSTRAINT users_email_unique UNIQUE (email);` |
| 删除约束 | `ALTER TABLE users DROP CONSTRAINT users_email_unique;` |
| 重命名约束 | `ALTER TABLE users RENAME CONSTRAINT old_name TO new_name;` |

不支持更改主键列的类型，也不支持更改外键引用列的类型。更多信息，请参见 [PostgreSQL 兼容性](/tidb-cloud/starter/postgresql-compatibility.md)。

## 删除数据库对象 {#drop-database-objects}

使用以下语句删除数据库对象：

```sql
DROP TABLE IF EXISTS users;
DROP INDEX IF EXISTS idx_users_name;
DROP VIEW IF EXISTS active_users;
DROP MATERIALIZED VIEW IF EXISTS user_summary;
```

可以使用 `CASCADE` 删除视图和物化视图等存在依赖关系的对象，但外键依赖关系必须单独处理：

```sql
DROP TABLE users CASCADE;
```

为避免留下悬空的外键约束，在删除表之前，请先删除引用该表的所有外键约束。外键依赖关系的处理方式与 PostgreSQL 不同。更多信息，请参见 [PostgreSQL 兼容性](/tidb-cloud/starter/postgresql-compatibility.md)。

## 截断表 {#truncate-a-table}

对单个表使用 `TRUNCATE` 或 `TRUNCATE TABLE`：

```sql
TRUNCATE TABLE users;
```

以下 PostgreSQL `TRUNCATE` 形式不受支持：

- 多表 `TRUNCATE`
- `CASCADE`
- `RESTRICT`
- `ONLY`
- `RESTART IDENTITY`
- `CONTINUE IDENTITY`

被外键引用的表不能被截断。

## 创建和管理数据库模式 {#create-and-manage-schemas}

创建数据库模式：

```sql
CREATE SCHEMA app;
```

在该数据库模式中创建对象：

```sql
CREATE TABLE app.settings (
    key TEXT PRIMARY KEY,
    value TEXT
);
```

当不再需要该数据库模式时，将其删除：

```sql
DROP SCHEMA app CASCADE;
```

## 创建和管理序列 {#create-and-manage-sequences}

创建序列：

```sql
CREATE SEQUENCE invoice_seq
START WITH 1000
INCREMENT BY 1;
```

使用序列：

```sql
SELECT nextval('invoice_seq');
```

使用 `setval()` 重新定位序列：

```sql
SELECT setval('invoice_seq', 2000);
```

`ALTER SEQUENCE` 支持 `OWNER TO` 和 `OWNED BY` 等所有权操作。其他 PostgreSQL `ALTER SEQUENCE` 选项不受支持。更多信息，请参见 [PostgreSQL 兼容性](/tidb-cloud/starter/postgresql-compatibility.md)。

## 其他 DDL 语句 {#other-ddl-statements}

以下常见 DDL 语句也受支持：

| 语句 | 说明 |
| --- | --- |
| `CREATE DATABASE` / `DROP DATABASE` | 创建或删除数据库。 |
| `CREATE TYPE` | 创建枚举类型或复合类型，但存在兼容性限制。 |
| `ALTER TYPE` | 支持部分枚举操作和 `RENAME TO`。 |
| `DROP TYPE` | 删除自定义类型，但存在依赖关系限制。 |
| `CREATE FUNCTION` / `DROP FUNCTION` | 创建或删除函数。 |
| `CREATE TRIGGER` / `DROP TRIGGER` | 创建或删除触发器。 |
| `CREATE COLLATION` / `DROP COLLATION` | 创建或删除排序规则。 |
| `CREATE EXTENSION` / `DROP EXTENSION` | 管理由 TiDB Cloud 提供的扩展。 |
| `COMMENT ON` | 为部分对象类型添加注释。 |
