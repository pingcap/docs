# TPC-H SF1000 (1TB): {{{ .lake }}} Warehouse Size Benchmark

このページでは、同じ TPC-H SF1000 ワークロードにおける Small、Medium、Large の {{{ .lake }}} Warehouse を比較します。SF1000 は、約 1TB の TPC-H データを表すためによく使用されます。

## データセットのスケール {#dataset-scale}

TPC-H Scale Factor 1000 (SF1000) は、生成データの約 1TB を表します。このデータセットには、標準の 8 つの TPC-H テーブルにまたがって約 60 億行が含まれています。

| テーブル | 行数 |
|---|---:|
| customer | 150,000,000 |
| lineitem | 6,000,000,000 |
| nation | 25 |
| orders | 1,500,000,000 |
| part | 200,000,000 |
| partsupp | 800,000,000 |
| region | 5 |
| supplier | 10,000,000 |

> **Note:**
>
> TPC Benchmark™ および TPC-H™ は、Transaction Processing Performance Council ([TPC](http://www.tpc.org)) の商標です。このテストは TPC-H に着想を得ていますが、公式な TPC-H の結果ではありません。

## サマリー {#summary}

| Warehouse サイズ | 合計時間 | Small 比の高速化 | 前のサイズ比の高速化 |
|---|---:|---:|---:|
| Small | 1173.32s | 1.00x | — |
| Medium | 537.93s | 2.18x | 2.18x |
| Large | 285.96s | 4.10x | 1.88x |

![TPC-H SF1000 Warehouse Size Benchmark](/media/tidb-cloud-lake/tpch-sf1000-warehouse-size-benchmark.png)

Medium は Small より約 2.18 倍高速です。Large は Small より約 4.10 倍高速で、22 クエリのワークロード全体を 5 分未満で完了します。

## 注意事項 {#notes}

全体のワークロードは、Warehouse サイズの増加に伴って明確にスケールします。一部の個別クエリは、クエリ形状、実行プラン、スケジューリング、キャッシュ動作の影響により、線形にスケールしない場合があります。
