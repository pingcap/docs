# エディション

{{{ .lake }}} には **Personal**、**Business**、**Dedicated** の 3 つのエディションがあり、幅広いニーズに対応し、さまざまなユースケースで最適なパフォーマンスを確保できるよう選択できます。

料金情報については、[Pricing & Billing](/tidb-cloud-lake/guides/pricing-billing.md) を参照してください。これらのエディション間の詳細な機能一覧については、[機能一覧](#feature-lists) を参照してください。

## 機能一覧 {#feature-lists}

以下は、エディションごとの {{{ .lake }}} の機能一覧です。

### リリース管理 {#release-management}

| 機能 | Personal | Business | Dedicated |
|----------|----------|----------|-----------|
| 毎週の新しいリリースへの早期アクセス。各リリースが本番アカウントにデプロイされる前に、追加のテストや検証に利用できます。 | | ✓ | ✓ |

### セキュリティとガバナンス {#security-governance}

| 機能 | Personal | Business | Dedicated |
|----------|----------|----------|-----------|
| SOC 2 Type II 認証。 | ✓ | ✓ | ✓ |
| GDPR | ✓ | ✓ | ✓ |
| すべてのデータの自動暗号化。 | ✓ | ✓ | ✓ |
| オブジェクトレベルのアクセス制御。 | ✓ | ✓ | ✓ |
| 変更または削除されたデータにアクセスまたは復元するための標準 Time Travel（最大 1 日）。 | ✓ | ✓ | ✓ |
| Fail-Safe による、変更または削除されたデータのディザスタリカバリ（Time Travel を超えて 7 日間）。 | ✓ | ✓ | ✓ |
| **拡張 Time Travel**。 | | 90 日 | 90 日 |
| テーブルまたはビュー内のカラムにマスキングポリシーを適用するためのカラムレベルセキュリティ。 | ✓ | ✓ | ✓ |
| Account Usage の ACCESS_HISTORY ビューを通じたユーザーアクセス履歴の監査。 | ✓ | ✓ | ✓ |
| **AWS PrivateLink を使用した {{{ .lake }}} サービスへのプライベート接続のサポート**。 | | ✓ | ✓ |
| **専用のメタデータストアとコンピュートリソースプール（仮想 Warehouse で使用）**。 | | | ✓ |

### コンピュートリソース {#compute-resource}

| 機能 | Personal | Business | Dedicated |
|----------|----------|----------|-----------|
| クエリとデータロードのワークロードを分離するための、独立したコンピュートクラスターである仮想 Warehouse。 | ✓ | ✓ | ✓ |
| マルチクラスター スケーリング | | ✓ | ✓ |
| 仮想 Warehouse のクレジット使用量を監視するためのリソースモニター。 | ✓ | ✓ | ✓ |

| 標準データ型の幅広いサポート。 | ✓ | ✓ | ✓ |
| 半構造化データ（JSON、ORC、Parquet）のネイティブサポート。 | ✓ | ✓ | ✓ |
| 地理空間データのネイティブサポート。 | ✓ | ✓ | ✓ |
| 非構造化データのネイティブサポート。 | ✓ | ✓ | ✓ |
| テーブルカラム内の文字列 / テキストデータに対する照合順序ルール。 | ✓ | ✓ | ✓ |
| 複数ステートメントのトランザクション。 | ✓ | ✓ | ✓ |
| JavaScript、Python、WebAssembly をサポートするユーザー定義関数（UDF）。 | | ✓ | ✓ |
| {{{ .lake }}} を他の開発プラットフォームに拡張するための外部関数。 | ✓ | ✓ | ✓ |
| 外部関数向けの Amazon API Gateway プライベートエンドポイント。 | ✓ | ✓ | ✓ |
| クラウドストレージのデータレイク内のデータを参照するための外部テーブル。 | ✓ | ✓ | ✓ |
| 非常に大きなテーブル内のデータをクラスタリングしてクエリパフォーマンスを向上させる機能。クラスタリングは自動的にメンテナンスされます。 | ✓ | ✓ | ✓ |
| ポイントルックアップクエリ向けの検索最適化。自動メンテナンス付き。 | ✓ | ✓ | ✓ |
| 結果が自動的にメンテナンスされるマテリアライズドビュー。 | ✓ | ✓ | ✓ |
| クラウドストレージのデータレイク内のデータを参照するための Iceberg テーブル。 | ✓ | ✓ | ✓ |
| stage に置かれた半構造化データファイル群のスキーマを自動検出し、カラム定義を取得するためのスキーマ検出。 | ✓ | ✓ | ✓ |
| データソースから受信した新しいデータの構造をサポートするために、テーブルを自動的に進化させる Schema Evolution。 | ✓ | ✓ | ✓ |
| [外部ロケーション付きテーブルの作成](/tidb-cloud-lake/sql/create-external-table.md) のサポート。 | ✓ | ✓ | ✓ |
| [ATTACH TABLE](/tidb-cloud-lake/sql/attach-table.md) のサポート。 | ✓ | ✓ | ✓ |
