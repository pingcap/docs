# コストの管理

**Manage** > **Billing** で、組織の当月の利用状況と請求履歴を確認できます。

## コストを制限する {#limiting-your-costs}

admin ユーザー向けに、{{{ .lake }}} では組織の支出上限を設定するオプションを提供しています。これにより、管理者はプラットフォーム上での支出額の上限を管理できます。設定するには、ホームページに移動して **Activate Spending Limit** をクリックします。次のページで、**Enable Spending Limit** ボタンをオンにし、組織に許可する月間最大支出額を指定できます。

> **Note:**
>
> 設定した支出上限は、各暦月に適用されます。たとえば、8 月 10 日に上限を設定した場合でも、その上限は 8 月 1 日から 31 日までの 8 月全体に対して有効になります。

支出上限を設定する際は、上限に達したときに {{{ .lake }}} がどのようなアクションを取るかを決める必要があります。現在、次の 2 つのオプションがあります。

- **Suspend Service**: 現在の月が終了するか、より高い上限を設定するまで、あなたの Warehouse は機能しません。

- **Send Notifications Only**: 組織の管理者は、支出上限に近づくとメール通知を受け取ります。あなたの Warehouse は引き続き正常に機能します。

"Send Notifications Only" オプションでは、{{{ .lake }}} は次の頻度サイクルに基づいて管理者にメール通知を送信します。

| 支出範囲 | 通知頻度 |
|---------------- |------------------------ |
| 80% - 90%       | 3 日ごと        |
| 90% - 100%      | 3 日ごと        |
| 100% 以上     | 3 日ごと        |

## 財務担当者にアクセス権を付与する {#granting-access-to-finance-personnel}

データセキュリティを確保しながら財務チームの作業を円滑に進めるために、{{{ .lake }}} 内で `billing` という名前のロールを作成できます。このロールは、請求関連情報のみにアクセスできるように特別に設計されています。

```sql
CREATE ROLE billing;
```

財務担当者を組織に招待する際は、この `billing` ロールを割り当ててください。

![alt text](/media/tidb-cloud-lake/billing-role.png)

{{{ .lake }}} にログインすると、請求ページのみに制限されたアクセス権が付与され、その他の業務関連ページはすべて表示されません。この方法により、{{{ .lake }}} 環境内の他の部分への不要なアクセスを制限し、機密データを保護できます。
