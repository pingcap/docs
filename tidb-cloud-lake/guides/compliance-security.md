# コンプライアンスとセキュリティ

{{{ .lake }}} はセキュリティを中核として構築されており、複数のセキュリティレイヤー、暗号化標準、コンプライアンス認証を通じて、お客様のデータを包括的に保護します。

## セキュリティ {#security}

{{{ .lake }}} は、お客様のデータを保護し、リソースへのアクセスを制御するために、複数のセキュリティレイヤーを実装しています。

### アクセス制御 {#access-control}

{{{ .lake }}} は、以下を組み合わせた包括的なアクセス制御システムを使用します。

- **Role-Based Access Control (RBAC)**: ユーザーに割り当てられたロールを通じて権限を管理します
- **Discretionary Access Control (DAC)**: リソース所有者が権限を直接付与できるようにします

### データ保護 {#data-protection}

**Masking Policy**: 機密データの表示方法をユーザーごとに制御することで、機密データを保護します。これにより、認可されたアクセスを維持しながら、プライバシー規制への準拠を支援します。

**Network Policy**: どの IP アドレスが {{{ .lake }}} リソースに接続できるかを制御し、特定のネットワークまたは場所からのアクセスのみに制限できます。

**Password Policy**: 長さ、複雑さ、ローテーションに関するカスタマイズ可能な要件を備えた強力なパスワードを強制し、不正アクセスを防止します。

### セキュア接続 {#secure-connectivity}

**PrivateLink**: トラフィックをパブリックインターネットに公開することなく、VPC と {{{ .lake }}} 間のプライベート接続を可能にします。設定手順については、[AWS PrivateLink で接続する](/tidb-cloud-lake/guides/connect-with-aws-privatelink.md) または [Alibaba Cloud PrivateLink で接続する](/tidb-cloud-lake/guides/connect-with-alibaba-cloud-privatelink.md) を参照してください。

## 暗号化 {#encryption}

### TLS 1.2 {#tls-12}

すべての通信に対してエンドツーエンド暗号化を提供しています。すべてのお客様データのフローは HTTPS のみを経由します。接続は、クライアントから {{{ .lake }}} API gateway まで TLS 1.2 を使用して暗号化され、以下を保証します。

- 転送中データの機密性
- 中間者攻撃に対する保護
- セキュアなクライアント-サーバー間通信

### ストレージ暗号化 {#storage-encryption}

{{{ .lake }}} Enterprise は、Object Storage Service (OSS) におけるサーバー側暗号化をサポートしています。この機能により、OSS に保存されるデータに対してサーバー側暗号化を有効化することで、データセキュリティとプライバシーを強化できます。ニーズに最も適した暗号化方式を選択できます。

- AES-256 encryption
- Customer-managed keys (CMK)
- Hardware security module (HSM) integration options

## コンプライアンス {#compliance}

{{{ .lake }}} では、データセキュリティとプライバシーを最優先事項としており、お客様のデータ保護への取り組みを裏付ける主要なコンプライアンスを達成しています。当社のセキュリティプラクティスは、最高水準の業界標準を満たしていることを確認するために、独立した第三者によって定期的に監査されています。

### SOC 2 Type II {#soc-2-type-ii}

当社は、独立監査人によって検証された SOC 2 Type II コンプライアンスを達成しています。この認証は、当社のシステムが、セキュリティ、可用性、処理の完全性、機密性、プライバシーに関する American Institute of Certified Public Accountants (AICPA) のトラストサービス基準に準拠していることを示しています。当社は、この基準を維持するために、運用管理を継続的に監視し、強化しています。

### GDPR {#gdpr}

{{{ .lake }}} は、個人のプライバシーと個人データを保護するために設計された欧州連合の規則である General Data Protection Regulation (GDPR) に準拠しています。当社の準拠には、厳格なデータプライバシーの実施、堅牢な暗号化、定期的なプライバシー監査が含まれており、EU 全域のユーザーの権利とデータプライバシーが保護されることを保証します。
