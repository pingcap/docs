# Dashboards

ダッシュボードは、**scorecards**、**pie charts**、**bar charts**、**line charts** など、さまざまな種類のチャートを通じてクエリ結果を表示するために使用されます。これらのチャートはクエリ結果から生成されます。Worksheet でクエリを実行した後、そのクエリ結果に基づいてチャートを作成できます。ダッシュボードを更新すると、チャートに対応するクエリを再実行して、最新の結果でチャートを更新できます。

![Alt text](/media/tidb-cloud-lake/dashboard.png)

## ダッシュボードの作成 {#creating-a-dashboard}

{{{ .lake }}} では、必要に応じて複数のダッシュボードを作成できます。1 つのダッシュボードには、1 つまたは複数のチャートを含めることができます。各チャートは特定のクエリ結果に対応していますが、複数のダッシュボードに追加できます。

**ダッシュボードを作成するには**:

1. Worksheet で、クエリ結果を使ってチャートを生成したいクエリを実行します。

2. 結果エリアで、**Chart** タブをクリックします。

    ![Alt text](/media/tidb-cloud-lake/chart-btn.png)

3. **Chart** タブで、右側のドロップダウンメニューからチャートタイプを選択します。次に、ドロップダウンリストの下にある **Data** タブと **Style** タブのオプションを使用して、データを指定し、チャートの外観をカスタマイズします。

    これらの集計関数は、クエリ結果の生データを要約し、有用なパターンを明らかにするのに役立ちます。使用できる集計関数は、選択したデータ型やチャートタイプによって異なります。

    | 関数                 | 説明 |
    |----------------------|----------------------------------------------------------------|
    | None                 | データに変更は加えられません。 |
    | Count                | クエリ結果内の対象フィールドのレコード数を計算します（NULL および '' の値を含むレコードは除きます）。 |
    | Min                  | クエリ結果内の最小値を計算します。 |
    | Max                  | クエリ結果内の最大値を計算します。 |
    | Median               | クエリ結果内の中央値を計算します。 |
    | Sum                  | クエリ結果内の数値の合計を計算します。 |
    | Average              | クエリ結果内の数値データの平均値を計算します。 |
    | Mode                 | クエリ結果内で最も頻繁に出現する値を特定します。 |

4. {{{ .lake }}} のホームページに戻り、左側のナビゲーションメニューで **Dashboards** を選択してから、**New Dashboard** をクリックします。

5. 新しいダッシュボードで、**Add Chart** をクリックします。左側のペインからチャートをダッシュボードにドラッグ＆ドロップします。左側のペインに複数のチャートがある場合は、必要な数だけ自由にドラッグできます。

> **Note:**
>
> Worksheet でクエリ結果からチャートを生成した後は、同じ Worksheet で別のクエリを実行しないでください。実行すると、そのチャートがダッシュボードで利用できなくなる可能性があります。

## ダッシュボードの共有 {#sharing-a-dashboard}

![alt text](/media/tidb-cloud-lake/dashboard-share.png)

ダッシュボードを共有する際は、他のユーザーのアクセス方法を制御するために、次のいずれかの権限レベルを選択できます。

- **Read Only**: ダッシュボードを表示できますが、変更したり、最新の結果を取得するためにクエリを実行したりすることはできません。
- **Execute**: クエリを実行して最新の結果を取得したり、ダッシュボードを変更せずに操作したりできます。
- **Edit**: クエリの変更や、結果の反映方法の変更を含め、ダッシュボードを変更できます。

他のユーザーから共有されたダッシュボードを表示するには、サイドバーで **Dashboards** をクリックし、右側の **Shared with Me** タブをクリックします。
