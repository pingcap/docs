# プラットフォームとリージョン

{{{ .lake }}} はクラウドネイティブなソリューションであり、現在、以下のクラウドプロバイダーとリージョンをサポートしています。

| クラウドプロバイダー | リージョン名             | リージョン ID   |
|----------------|--------------------------|----------------|
| AWS            | 米国西部 (オレゴン)      | us-west-2      |
| AWS            | アジアパシフィック (東京) | ap-northeast-1 |
| AWS            | 米国東部 (N. Virginia)   | us-east-1      |
| AWS            | アジアパシフィック (シンガポール) | ap-southeast-1 |
| AWS            | アジアパシフィック (ムンバイ) | ap-south-1     |
| Alibaba Cloud  | 日本 (東京)              | ap-northeast-1 |

> **Note:**
>
> - 効率的で安定したデータ同期およびインポートのために、現在の環境に一致するクラウドプロバイダーとリージョンを選択することを強く推奨します。この構成により、ネットワークをまたぐ転送と、それに伴うネットワーク遅延やデータ損失のリスクが軽減され、データ転送プロセスの安全性と円滑性が確保されます。
> - {{{ .lake }}} では、今後さらに多くのクラウドプロバイダーとリージョンのサポートを拡大する予定です。現在ご利用中のクラウドプロバイダーまたはリージョンがサポートされていない場合は、[Contact Sales](https://www.pingcap.com/contact-us/) をクリックして {{{ .lake }}} チームまでお問い合わせください。

{{{ .lake }}} アカウントにサインアップする際には、クラウドプラットフォームとリージョンを選択する必要があります。アカウントの作成が完了すると、選択したクラウドプラットフォームとリージョンは変更できません。
