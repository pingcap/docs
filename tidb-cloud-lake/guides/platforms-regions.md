# プラットフォームとリージョン

{{{ .lake }}} はクラウドネイティブなソリューションであり、現在、以下のクラウドプロバイダーとリージョンをサポートしています。

| クラウドプロバイダー | リージョン名             | リージョン ID   |
|----------------|--------------------------|----------------|
| AWS            | US West (Oregon)         | us-west-2      |
| AWS            | Asia Pacific (Tokyo)     | ap-northeast-1 |
| AWS            | US East (N. Virginia)    | us-east-1      |
| AWS            | Asia Pacific (Singapore) | ap-southeast-1 |
| AWS            | Asia Pacific (Mumbai)    | ap-south-1     |
| Alibaba Cloud  | Japan (Tokyo)            | ap-northeast-1 |
| Alibaba Cloud  | Singapore                | ap-southeast-1 |

> **Note:**
>
> - 効率的で安定したデータ同期およびインポートのために、現在の環境に一致するクラウドプロバイダーとリージョンを選択することを強く推奨します。この設定により、ネットワークをまたぐ転送と、それに伴うネットワークレイテンシーやデータ損失のリスクが軽減され、データ転送プロセスの安全性と円滑性が確保されます。
> - {{{ .lake }}} では、今後さらに多くのクラウドプロバイダーとリージョンのサポートを拡大する予定です。現在ご利用中のクラウドプロバイダーまたはリージョンがサポートされていない場合は、[Contact Sales](https://www.pingcap.com/contact-us/) をクリックして {{{ .lake }}} チームまでお問い合わせください。

{{{ .lake }}} アカウントにサインアップする際には、クラウドプラットフォームとリージョンを選択する必要があります。アカウントの作成が完了すると、選択したクラウドプラットフォームとリージョンは変更できません。
