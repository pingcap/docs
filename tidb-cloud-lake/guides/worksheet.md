# Worksheets

{{{ .lake }}} の Worksheets は、SQL ステートメントの整理、実行、保存に使用されます。また、組織内の他のユーザーと共有することもできます。

## Worksheet の作成 {#creating-a-worksheet}

新しい Worksheet を作成するには、サイドバーの **Worksheets** をクリックし、**New Worksheet** を選択します。

SQL ステートメントがすでに SQL ファイルに保存されている場合は、そのファイルから直接 Worksheet を作成することもできます。これを行うには、**New Worksheet** の右側にある省略記号アイコン <svg t="1722479222306" class="icon" viewBox="0 0 1024 1024" version="1.1" xmlns="http://www.w3.org/2000/svg" p-id="2315" width="16" height="16"><path d="M213.333333 512a85.333333 85.333333 0 1 1-85.333333-85.333333 85.333333 85.333333 0 0 1 85.333333 85.333333z m298.666667-85.333333a85.333333 85.333333 0 1 0 85.333333 85.333333 85.333333 85.333333 0 0 0-85.333333-85.333333z m384 0a85.333333 85.333333 0 1 0 85.333333 85.333333 85.333333 85.333333 0 0 0-85.333333-85.333333z" fill="#1677FF" p-id="2316"></path></svg> をクリックし、**Create from SQL File** を選択します。

クエリ結果は出力エリアに表示されます。**Export** をクリックして結果全体を CSV ファイルに保存することも、出力エリアで 1 つまたは複数のセルを選択して Command + C（Mac）または Ctrl + C（Windows）を押し、クリップボードにコピーすることもできます。

> **Tip:**
>
> - 1 回の API 呼び出しで複数の SQL ステートメントを実行することはサポートされていません。Worksheet 内の各 SQL クエリは、必ず 1 つのセミコロン (;) で終了してください。
> - SQL ステートメントをより簡単に編集できるように、データベースリストでテーブルを選択し、その横にある "..." ボタンをクリックできます。次に、メニューの案内に従って、テーブル名またはすべてのカラム名をワンクリックで右側の SQL 入力エリアにコピーできます。
>
> - SQL 入力エリアに複数のステートメントを入力した場合、{{{ .lake }}} はカーソルが置かれているステートメントのみを実行します。カーソルを移動して他のステートメントを実行できます。さらに、キーボードショートカットも使用できます。Ctrl + Enter（Windows）または Command + Enter（Mac）で現在のステートメントを実行し、Ctrl + Shift + Enter（Windows）または Command + Shift + Enter（Mac）で全ステートメントを実行します。

## クエリ結果のデフォルト設定 {#query-result-defaults}

{{{ .lake }}} は、Worksheet の出力エリアに表示されるクエリ結果に対して、次のデフォルト制限を適用します。

| 設定 | デフォルト | 説明 |
|---|---|---|
| 最大表示行数 | 10,000 | プレビューには最初の 10,000 行のみが表示されます。 |
| 最大表示カラム数 | 200 | プレビューには最初の 200 カラムのみが表示されます。 |
| 最大セル内容長 | 3,000 文字 | これより長いセル値は表示時に切り詰められます。 |

行数とカラム数の制限は固定です。最大セル内容長を調整するには、結果エリアの右下にある設定アイコンをクリックし、値（3K–Unlimited）を選択します。非常に大きな値または **Unlimited** を設定すると、大きな結果セットを扱う際にブラウザの動作が遅くなったり、応答しなくなったりする可能性があることに注意してください。

## Worksheet の共有 {#sharing-a-worksheet}

Worksheet は、組織内の全員または特定の個人と共有できます。これを行うには、共有したい Worksheet で **Share** をクリックするか、Worksheet フォルダを共有する場合は **Share this Folder** をクリックします。

![Alt text](/media/tidb-cloud-lake/share.png)

表示されるダイアログボックスで、共有範囲を選択します。リンクをコピーして対象の受信者に共有でき、受信者にはメール通知も送信されます。**Designated Members** の範囲を選択した場合、共有を成功させるには受信者が共有されたリンクをクリックする必要がある点に注意してください。

- 他のユーザーから共有された Worksheet を表示するには、サイドバーの **Worksheets** をクリックし、右側の **Shared with Me** タブをクリックします。
- Worksheet を他のユーザーと共有すると、必要な権限を持っていればその中の SQL ステートメントを実行できますが、ステートメントを編集することはできません。

## クエリ結果のエクスポート {#exporting-query-results}

{{{ .lake }}} ではクエリ結果をエクスポートできます。ただし、この機能を使用するには、組織の Owner がチームメンバーに **EXPORT** 権限を付与する必要があります。データセキュリティ上の理由により、この機能はデフォルトで無効になっています。

この機能を使用する必要がある場合は、組織の Owner に連絡して権限を有効化してもらってください（**Admin** > **Users & Roles**）。
