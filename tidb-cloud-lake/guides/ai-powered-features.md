# AI を活用した機能

AI を活用した機能の搭載により、{{{ .lake }}} では自然言語で会話しながら、ヘルプ、支援、解決策を得ることができます。これらの AI 機能はデフォルトで有効になっていますが、必要に応じて **Manage** > **Settings** に移動して無効にできます。

## 支援のための AI Chat {#ai-chat-for-assistance}

AI Chat は自然言語による対話を可能にし、直感的な情報取得と効率的な問題解決を実現します。

AI Chat を起動するには、次の手順を実行します。

1. サイドバーにある虫眼鏡アイコン <svg t="1723600475826" class="icon" viewBox="0 0 1024 1024" version="1.1" xmlns="http://www.w3.org/2000/svg" p-id="2903" width="16" height="16"><path d="M949.76 884.3264a88.68864 88.68864 0 0 1-25.64096 62.67904 87.14752 87.14752 0 0 1-123.76576 0.16896l-164.29568-160.87552a382.4128 382.4128 0 0 1-26.43968 12.6208 382.83776 382.83776 0 0 1-300.032 0 383.38048 383.38048 0 0 1-122.48064-83.39968 391.296 391.296 0 0 1 0-550.36928 384.56832 384.56832 0 0 1 627.55328 123.648 391.00416 391.00416 0 0 1-40.704 376.57088l150.32832 156.56448a88.576 88.576 0 0 1 25.47712 62.39232z" fill="#1677FF" p-id="2904"></path></svg> をクリックして、検索ボックスを開きます。

2. **Chat** タブに切り替えます。

3. 質問を入力します。

### AI を活用した SQL Assistant {#ai-powered-sql-assistant}

Worksheet 内で SQL ステートメントを編集する際に、AI 支援を利用できます。SQL を最初から自分で書く必要はありません。AI が生成を支援します。

SQL ステートメントの編集中に AI を利用するには、新しい行の先頭で "/" を入力し、その後に "return current time" のようなクエリを入力します。

![Alt text](/media/tidb-cloud-lake/ai-worksheet-1.gif)

既存の SQL ステートメントに対しても AI 支援を利用できます。その場合は、対象の SQL を選択して **Edit** をクリックし、希望する変更内容を指定するか、追加の支援を依頼します。あるいは、**Chat** をクリックして AI と会話し、より包括的なサポートを受けることもできます。

![Alt text](/media/tidb-cloud-lake/ai-worksheet-2.gif)
