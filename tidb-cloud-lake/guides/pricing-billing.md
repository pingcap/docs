# TiDB Cloud Lake の料金と請求

{{{ .lake }}} で発生する費用は、Warehouse、ストレージ、クラウドサービス、およびサービスホスティング料金の各コンポーネントで構成されます。このページでは、各コンポーネントの料金と請求の仕組みについて説明します。

## {{{ .lake }}} の料金 {#lake-pricing}

このセクションでは、Warehouse、ストレージ、クラウドサービス、およびサービスホスティングの料金情報を紹介します。

### Warehouse の料金 {#warehouse-pricing}

Warehouse は実行中（具体的には Running 状態）のときに費用が発生します。費用は Warehouse のサイズと実行時間によって決まります。**請求は秒単位で計算されます**。たとえば、Warehouse を 3 秒間実行した場合、その正確な時間分だけ課金されます。

Warehouse のサイズとは、同時に処理できるクエリの最大数を指します。料金は、利用可能なサイズと使用している {{{ .lake }}} エディションによって異なります。

| Size    | 1 時間あたりの料金 (Personal)     | 1 時間あたりの料金 (Business)     |
|---------|-----------------------------------|-----------------------------------|
| XSmall  | $1.6                              | $2.4                              |
| Small   | $3.2                              | $4.8                              |
| Medium  | $6.4                              | $9.6                              |
| Large   | $12.8                             | $19.2                             |
| XLarge  | $25.6                             | $38.4                             |
| 2XLarge | $51.2                             | $76.8                             |
| 3XLarge | $102.4                            | $153.6                            |
| 4XLarge | $204.8                            | $307.2                            |
| 5XLarge | $409.6                            | $614.4                            |
| 6XLarge | $819.2                            | $1228.8                           |

一時停止された Warehouse はリソースを消費しません。デフォルトでは、{{{ .lake }}} はリソースとコストを節約するため、5 分間アクティビティがないと Warehouse を自動的に一時停止します。この自動一時停止機能は、必要に応じて調整または無効化できます。

### ストレージ料金 {#storage-pricing}

{{{ .lake }}} 内のデータは、物理的には Amazon S3 に保存されます。{{{ .lake }}} のストレージ料金は Amazon S3 の料金に基づきます。現在、Personal Edition と Business Edition のどちらも、1 テラバイト (TB) あたり月額 $23.00 です。

| エディション          | 1 TB あたりの月額料金 |
| ---------------- | ---------------------- |
| Personal Edition | $23.00                 |
| Business Edition | $23.00                 |

### クラウドサービス料金 {#cloud-service-pricing}

現在、クラウドサービス料金には API リクエストの料金が含まれています。{{{ .lake }}} で SQL クエリを実行するたびに、{{{ .lake }}} HTTP ハンドラーを介して `lake-query` に REST API リクエストが送信されます。Personal Edition では API リクエスト 10,000 回ごとに $1、Business Edition では API リクエスト 10,000 回ごとに $2 が課金されます。

| エディション          | API リクエスト 10,000 回あたりの料金 |
| ---------------- | ------------------------------------ |
| Personal Edition | $1.00                                |
| Business Edition | $2.00                                |

### サービスホスティング料金 {#service-hosting-pricing}

サービスホスティング料金は、データ統合サービスに適用されます。Warehouse とは異なり、データ統合サービスは通常、停止するまで継続的に（24 時間 365 日）実行されます。請求モデルは Warehouse と同じで、実際の実行時間に基づいて秒単位で計算され、料金はサービスサイズと使用している {{{ .lake }}} エディションによって決まります。

サービスサイズは XSmall Warehouse サイズを基準にしています。次の表の月額料金は、1 か月を 720 時間（30 日）として 24 時間 365 日連続稼働した場合の概算であり、参考値として示しています。

| Size    | 1 時間あたりの料金 (Personal) | 1 時間あたりの料金 (Business) | 月額料金 (Personal, 24/7) | 月額料金 (Business, 24/7) |
|---------|------------------------|------------------------|--------------------------------|--------------------------------|
| 4XSmall | $0.20                  | $0.30                  | $144                           | $216                           |
| 3XSmall | $0.40                  | $0.60                  | $288                           | $432                           |
| 2XSmall | $0.80                  | $1.20                  | $576                           | $864                           |

## 例 1 {#example-1}

**利用シナリオ:** ユーザーが XSmall Warehouse (Business) を使用して、ときどきデータをクエリしています。この特定のクエリには 5 分 20 秒かかり、データ保存サイズは 100GB です。

| コスト | 計算式 | 金額 |
|------|---------|--------|
| Warehouse | $2.4 ÷ 3600 × (5×60+20) | $0.21 |
| Storage | $23 ÷ 1024 ÷ 30 × 100 | $0.07 |
| **日次合計** | | **$0.28** |
| **月次合計** | | **$8.40** |

## 例 2 {#example-2}

**利用シナリオ:** ユーザーが XSmall Warehouse (Business) を使用して、{{{ .lake }}} に継続的にデータをインポートしています。Warehouse は 1TB のストレージで 24 時間稼働し、1 分ごとのデータのロード (load) には Task service を使用しています。API 呼び出し数の見積もりは 50,000 回です。

| コスト | 計算式 | 金額 |
|------|---------|--------|
| Warehouse | $2.40 × 24h | $57.60/day |
| Storage | $23 ÷ 30 | $0.77/day |
| Cloud Service | $2 × 5 | $10.00/day |
| **日次合計** | | **$68.37** |
| **月次合計** | | **$2,051.10** |

## {{{ .lake }}} の請求 {#lake-billing}

請求期間は各暦月ごとに設定されており、毎月 1 日から月末までです。初月については、請求期間は組織が作成された日から開始されます。

請求の詳細を確認するには、**Manage** に移動して **Billing** をクリックします。そこで請求書を確認し、支払い用のクレジットカードを登録できます。

{{{ .lake }}} はユーザーへの請求時に、まずバウチャーを適用します。複数のバウチャーが利用可能な場合、システムは有効期限が最も早いバウチャーから優先的に差し引きます。バウチャーは有効期限までに使用してください。
