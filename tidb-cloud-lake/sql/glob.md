# GLOB

使用通配符字符执行大小写敏感的模式匹配：

- `?` 匹配任意单个字符。
- `*` 匹配零个或多个字符。

## 语法 {#syntax}

```sql
GLOB(<string>, <pattern>)
```

## 返回类型 {#return-type}

返回 BOOLEAN：如果输入字符串与模式匹配，则为 `true`；否则为 `false`。

## 示例 {#examples}

```sql
SELECT
    GLOB('abc', 'a?c'),
    GLOB('abc', 'a*d'),
    GLOB('abc', 'abc'),
    GLOB('abc', 'abcd'),
    GLOB('abcdef', 'a?c*'),
    GLOB('hello', 'h*l');;

┌────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ glob('abc', 'a?c') │ glob('abc', 'a*d') │ glob('abc', 'abc') │ glob('abc', 'abcd') │ glob('abcdef', 'a?c*') │ glob('hello', 'h*l') │
├────────────────────┼────────────────────┼────────────────────┼─────────────────────┼────────────────────────┼──────────────────────┤
│ true               │ false              │ true               │ false               │ true                   │ false                │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```
