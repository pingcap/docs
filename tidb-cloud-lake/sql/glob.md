# GLOB

ワイルドカード文字を使用して、大文字と小文字を区別するパターンマッチングを実行します。

- `?` は任意の 1 文字に一致します。
- `*` は 0 文字以上に一致します。

## 構文 {#syntax}

```sql
GLOB(<string>, <pattern>)
```

## 戻り値の型 {#return-type}

BOOLEAN を返します。入力文字列がパターンに一致する場合は `true`、それ以外の場合は `false` です。

## 例 {#examples}

```sql
SELECT
    GLOB('abc', 'a?c'),
    GLOB('abc', 'a*d'),
    GLOB('abc', 'abc'),
    GLOB('abc', 'abcd'),
    GLOB('abcdef', 'a?c*'),
    GLOB('hello', 'h*l');;

┌────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ glob('abc', 'a?c') │ glob('abc', 'a*d') │ glob('abc', 'abc') │ glob('abc', 'abcd') │ glob('abcdef', 'a?c*') │ glob('hello', 'h*l') │
├────────────────────┼────────────────────┼────────────────────┼─────────────────────┼────────────────────────┼──────────────────────┤
│ true               │ false              │ true               │ false               │ true                   │ false                │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```
