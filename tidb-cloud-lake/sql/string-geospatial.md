# TO_STRING

GEOMETRY オブジェクトを String 表現に変換します。出力データの表示形式は `geometry_output_format` 設定によって制御され、この設定には以下の種類があります。

| パラメータ | 説明 |
|-------------------|---------------------------------------------------------------------|
| GeoJSON (default) | GEOMETRY の結果は、GeoJSON 形式の JSON オブジェクトとしてレンダリングされます。 |
| WKT               | GEOMETRY の結果は、WKT 形式の文字列としてレンダリングされます。          |
| WKB               | GEOMETRY の結果は、WKB 形式のバイナリとしてレンダリングされます。          |
| EWKT              | GEOMETRY の結果は、EWKT 形式の文字列としてレンダリングされます。         |
| EWKB              | GEOMETRY の結果は、EWKB 形式のバイナリとしてレンダリングされます。         |

## 構文 {#syntax}

```sql
TO_STRING(<geometry>)
```

## 引数 {#arguments}

| 引数 | 説明 |
|--------------|------------------------------------------------------|
| `<geometry>` | 引数は GEOMETRY 型の式である必要があります。 |

## 戻り値の型 {#return-type}

String。

## 例 {#examples}

```sql
SET geometry_output_format='GeoJSON';

SELECT
  TO_GEOMETRY(
    ST_GEOMETRYFROMWKT(
      'SRID=4326;LINESTRING(400000 6000000, 401000 6010000)'
    )
  ) AS pipeline_geometry;
```
