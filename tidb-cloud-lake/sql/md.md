# MD5

文字列の MD5 128 ビットチェックサムを計算します。値は 32 桁の 16 進数文字列として返され、引数が NULL の場合は NULL が返されます。

## 構文 {#syntax}

```sql
MD5(<expr>)
```

## 例 {#examples}

```sql
SELECT MD5('1234567890');

┌──────────────────────────────────┐
│         md5('1234567890')        │
├──────────────────────────────────┤
│ e807f1fcf82d132f9bb018ca6738a19f │
└──────────────────────────────────┘
```
