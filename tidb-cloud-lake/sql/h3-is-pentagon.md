# H3_IS_PENTAGON

指定された [H3](https://eng.uber.com/h3/) インデックスが五角形セルを表すかどうかを確認します。

## 構文 {#syntax}

```sql
H3_IS_PENTAGON(h3)
```

## 例 {#examples}

```sql
SELECT H3_IS_PENTAGON(599119489002373119);

┌────────────────────────────────────┐
│ h3_is_pentagon(599119489002373119) │
├────────────────────────────────────┤
│ true                               │
└────────────────────────────────────┘
```
