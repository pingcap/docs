# TO_DECIMAL

値を DECIMAL データ型に変換します。

## 構文 {#syntax}

```sql
TO_DECIMAL
( <expr> [, '<format>' ] [, <precision> [, <scale> ] ] )
```

## 引数 {#arguments}

| 引数 | 説明                                                                                                                                                                             |
|-----------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| expr      | boolean、number、string、または variant 型の式です。                                                                                                                            |
| format    | 任意。10 進数の結果に対して必要な precision と scale を指定するフォーマット文字列です。合計桁数と小数点以下の桁数を定義できます。 |
| precision | 任意。結果の有効桁数の合計です。デフォルトは 38 です。                                                                                                          |
| scale     | 任意。小数点以下の桁数です。precision を超えてはならず、デフォルトは 0 です。                                                                                        |

### フォーマット指定子 {#format-specifiers}

| フォーマット指定子   | 説明                                                                     | 入力例 |
|--------------------|---------------------------------------------------------------------------------|---------------|
| '9'                | 任意の数字です（数字または何もない状態を受け入れますが、この実装では 1 桁必要です） | "123"         |
| '0'                | 必須の数字です（現在の実装では 9 と同じです）                            | "123"         |
| 'D'                | 小数点です（'.' または ',' を受け入れ、常に '.' に正規化されます）                    | "12.34"       |
| 'G'                | 桁区切り（千単位）記号です（入力では ',' を想定します）                              | "1,234"       |
| 'S'                | 符号です（'+' または '-'。結果の先頭に適用されます）                                  | "-123"        |
| リテラル文字  | 任意のリテラル文字は、入力内に正確に現れる必要があります                          | "NT$123"      |

## 例 {#examples}

```sql
SELECT TO_DECIMAL('1234.56');

╭───────────────────────╮
│ to_decimal('1234.56') │
├───────────────────────┤
│                  1235 │
╰───────────────────────╯

SELECT TO_DECIMAL('1234.56', '9999D99');

╭──────────────────────────────────╮
│ to_decimal('1234.56', '9999D99') │
├──────────────────────────────────╤
│                             1235 │
╰──────────────────────────────────╯

SELECT TO_DECIMAL('1234.56', 38, 1);

╭──────────────────────────────╮
│ to_decimal('1234.56', 38, 1) │
├──────────────────────────────┤
│                       1234.6 │
╰──────────────────────────────╯

SELECT TO_DECIMAL('NT$1234.56', 'NT$9999D99', 38, 1);

╭───────────────────────────────────────────────╮
│ to_decimal('NT$1234.56', 'NT$9999D99', 38, 1) │
├───────────────────────────────────────────────┤
│                                        1234.6 │
╰───────────────────────────────────────────────╯

```
