# MAP_KEYS

マップ内のキーを返します。

## 構文 {#syntax}

```sql
MAP_KEYS( <map> )
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|----------------|
| `<map>`   | 入力マップです。 |

## 戻り値の型 {#return-type}

Array。

## 例 {#examples}

```sql
SELECT MAP_KEYS({'a':1,'b':2,'c':3});

┌───────────────────────────────┐
│ map_keys({'a':1,'b':2,'c':3}) │
├───────────────────────────────┤
│ ['a','b','c']                 │
└───────────────────────────────┘
```
