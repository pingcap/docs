# PREVIOUS_DAY

指定された日付またはタイムスタンプより前にある、指定した曜日の直近の日付を返します。

## 構文 {#syntax}

```sql
PREVIOUS_DAY(<date_expression>, <target_day>)
```

| パラメータ          | 説明                                                                                                                                                                     |
|---------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `<date_expression>` | 指定した曜日の直前の出現日を計算するための `DATE` または `TIMESTAMP` 値です。                                                                                           |
| `<target_day>`      | 直前の出現日を検索する対象の曜日です。指定できる値は `monday`、`tuesday`、`wednesday`、`thursday`、`friday`、`saturday`、`sunday` です。 |

## 戻り値の型 {#return-type}

Date。

## 例 {#examples}

たとえば、2024-11-13 のような指定日より前の直近の金曜日を求める場合は、次のようにします。

```sql
SELECT PREVIOUS_DAY(to_date('2024-11-13'), friday) AS last_friday;

┌─────────────┐
│ last_friday │
├─────────────┤
│ 2024-11-08  │
└─────────────┘
```
