# DATE_SUB

指定した日付または日時（timestamp/datetime）から、時間間隔または日付間隔を減算します。

## 構文 {#syntax}

```sql
DATE_SUB(<unit>, <value>,  <date_or_time_expr>)
```

## 引数 {#arguments}

| 引数                  | 説明                                                                                           |
|-----------------------|------------------------------------------------------------------------------------------------|
| `<unit>`              | 次のいずれかの値である必要があります: `YEAR`, `QUARTER`, `MONTH`, `DAY`, `HOUR`, `MINUTE`, `SECOND` |
| `<value>`             | 加算したい時間単位の数です。たとえば、2 日を加算したい場合、この値は 2 になります。                         |
| `<date_or_time_expr>` | `DATE` または `TIMESTAMP` 型の値                                                               |

## 戻り値の型 {#return-type}

この関数は、`<date_or_time_expr>` 引数と同じ型の値を返します。

## 例 {#examples}

```sql
SELECT date_sub(YEAR, 1, to_date('2018-01-02'));

┌──────────────────────────────────────────┐
│ date_sub(year, 1, to_date('2018-01-02')) │
├──────────────────────────────────────────┤
│ 2017-01-02                               │
└──────────────────────────────────────────┘
```
