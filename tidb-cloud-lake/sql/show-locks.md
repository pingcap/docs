# SHOW LOCKS

テーブルに対して現在ロックを保持しているアクティブなトランザクションの一覧を表示します。対象は、現在のユーザーのすべてのセッション、または {{{ .lake }}} システム内のすべてのユーザーです。ロックは、テーブルなどの共有リソースへのアクセスを制限する同期メカニズムであり、{{{ .lake }}} システム内のプロセスまたはスレッド間のやり取りを秩序立てて制御し、データの整合性を維持して競合を防ぐために使用されます。

[UPDATE](/tidb-cloud-lake/sql/update.md)、[DELETE](/tidb-cloud-lake/sql/delete.md)、[OPTIMIZE TABLE](/tidb-cloud-lake/sql/optimize-table.md)、[RECLUSTER TABLE](/tidb-cloud-lake/sql/recluster-table.md)、および [ALTER TABLE](/tidb-cloud-lake/sql/alter-table.md#column-operations) などの操作により、システム内でテーブルロックが発生することがあります。テーブルロック機能はデフォルトで有効になっています。リソース競合が発生した場合は、このコマンドを使用して詳細を確認できます。この機能を無効にするには、`set enable_table_lock=0;` を実行します。

## 構文 {#syntax}

```sql
SHOW LOCKS [IN ACCOUNT] [WHERE <expr>]
```

| パラメーター | 説明 |
|------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| IN ACCOUNT | {{{ .lake }}} システム内のすべてのユーザーのロック情報を表示します。省略した場合、このコマンドは現在のユーザーのすべてのセッションにおけるロックを返します。 |
| WHERE      | ステータスに基づいてロックを絞り込みます。有効な値は `HOLDING` と `WAITING` です。 |

## 出力 {#output}

このコマンドは、次のカラムを含むテーブル形式でロック情報を返します。

| カラム      | 説明                                                                                                                                                                                                             |
|-------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| table_id    | ロックに関連付けられたテーブルの内部 ID。                                                                                                                                                                     |
| revision    | ロックを開始したトランザクションのバージョンを示すリビジョン番号です。0 から始まり、後続のトランザクションごとに増加することで、すべてのトランザクションにわたる包括的な順序を確立します。 |
| type        | `TABLE` などのロックの種類。                                                                                                                                                                                      |
| status      | `HOLDING` または `WAITING` などのロックの状態。                                                                                                                                                                 |
| user        | ロックに関連付けられたユーザー。                                                                                                                                                                                      |
| node        | ロックが保持されているクエリノードの識別子。                                                                                                                                                                    |
| query_id    | ロックに関連するクエリセッション ID。デッドロックやロック保持時間が過度に長い場合に、これを使用してクエリを [KILL](/tidb-cloud-lake/sql/kill.md) できます。                                                  |
| created_on  | ロックを開始したトランザクションが作成された時刻。                                                                                                                                                     |
| acquired_on | ロックが取得された時刻。                                                                                                                                                                                   |
| extra_info  | ロックに関連する追加情報（存在する場合）。                                                                                                                                                                     |
