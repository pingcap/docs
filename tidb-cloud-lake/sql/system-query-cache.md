# system.query_cache

クエリ ID、結果サイズ、キャッシュされたデータの場所など、キャッシュされたクエリ結果に関する情報を格納します。

| カラム               | Type    | 説明                                                                    |
|----------------------|---------|-------------------------------------------------------------------------|
| `sql`                | String  | キャッシュされたクエリの元の SQL テキストです。                         |
| `query_id`           | String  | 結果がキャッシュされているクエリの一意な識別子です。                    |
| `result_size`        | UInt64  | キャッシュされた結果ファイルのサイズ（バイト単位）です。                |
| `num_rows`           | UInt64  | キャッシュされた結果の行数です。                                        |
| `partitions_sha`     | String  | キャッシュの整合性を検証するために使用されるソースパーティションのハッシュです。 |
| `location`           | String  | キャッシュされた結果ファイルの保存場所（例: 内部パス）です。            |
| `active_result_scan` | Boolean | キャッシュされた結果が現在 `RESULT_SCAN` によって使用されているかどうかです。 |
