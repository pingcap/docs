# ROLLBACK

撤销事务期间所做的所有更改。[BEGIN](/tidb-cloud-lake/sql/begin.md) 和 [COMMIT](/tidb-cloud-lake/sql/commit.md)/ROLLBACK 必须配合使用，用于启动事务，然后保存或撤销该事务。

## 语法 {#syntax}

```sql
ROLLBACK
```
