# ROLLBACK

トランザクション中に行われたすべての変更を取り消します。トランザクションを開始し、その後保存または取り消すには、[BEGIN](/tidb-cloud-lake/sql/begin.md) と [COMMIT](/tidb-cloud-lake/sql/commit.md)/ROLLBACK を組み合わせて使用する必要があります。

## 構文 {#syntax}

```sql
ROLLBACK
```
