# TO_START_OF_MONTH

将日期或带时间的日期（时间戳/datetime）向下舍入到当月的第一天。返回日期。

## 语法 {#syntax}

```sql
TO_START_OF_MONTH(<expr>)
```

## 参数 {#arguments}

| 参数 | 描述 |
|-----------|----------------|
| `<expr>`  | 日期/时间戳 |

## 返回类型 {#return-type}

`DATE`，以 “YYYY-MM-DD” 格式返回日期。

## 示例 {#examples}

```sql
SELECT
  to_start_of_month('2023-11-12 09:38:18.165575');

┌─────────────────────────────────────────────────┐
│ to_start_of_month('2023-11-12 09:38:18.165575') │
├─────────────────────────────────────────────────┤
│ 2023-11-01                                      │
└─────────────────────────────────────────────────┘
```
