# QUERY_HISTORY

分析および監視のためにクエリ実行ログを取得します。

## 構文 {#syntax}

```sql
QUERY_HISTORY
    [ BY WAREHOUSE <warehouse_name> ]
    [ FROM '<timestamp>' ]
    [ TO '<timestamp>' ]
    [ LIMIT <unsigned_integer> ]
```

| パラメータ | 説明 |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `BY WAREHOUSE` | 任意。ログを特定の Warehouse に絞り込みます。名前が空の場合はエラーになります。 |
| `FROM`         | 任意。クエリ範囲の開始タイムスタンプです。形式: `YYYY-MM-DD HH:MM:SS`（UTC または明示的なタイムゾーン）。デフォルトは `TO` の 1 時間前です。 |
| `TO`           | 任意。クエリ範囲の終了タイムスタンプです。形式: `YYYY-MM-DD HH:MM:SS`（UTC または明示的なタイムゾーン）。デフォルトは現在時刻です。 |
| `LIMIT`        | 任意。返されるレコードの最大数です。デフォルトは `10` です。正の整数である必要があります。 |

## 出力カラム {#output-columns}

結果には、次のようなカラムが含まれます。

| カラム       | 説明 |
| ------------ | ------------------------------------- |
| `query_id`   | クエリの一意識別子 |
| `query_text` | 実行された SQL 文 |
| `scan_bytes` | スキャンされたデータ量 |
| ...          | 追加のクエリメトリクスおよびメタデータ |

## 例 {#examples}

特定の Warehouse の最近のクエリ履歴を取得します。

```sql
QUERY_HISTORY
    BY WAREHOUSE 'etl-wh'
    FROM '2023-08-20 00:00:00'
    TO '2023-08-20 06:00:00'
    LIMIT 200;
```

すべての Warehouse を対象に直近 10 件のクエリを取得します。

```sql
QUERY_HISTORY;
```

カスタムの制限件数を指定してクエリ履歴を取得します。

```sql
QUERY_HISTORY LIMIT 50;
```
