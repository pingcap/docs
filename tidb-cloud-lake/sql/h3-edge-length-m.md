# H3_EDGE_LENGTH_M

返回给定分辨率下六边形边长的平均值（单位为米）。不包括五边形。

## 语法 {#syntax}

```sql
H3_EDGE_LENGTH_M(1)
```

## 示例 {#examples}

```sql
┌─────────────────────┐
│ h3_edge_length_m(1) │
├─────────────────────┤
│   483056.8390711111 │
└─────────────────────┘
```
