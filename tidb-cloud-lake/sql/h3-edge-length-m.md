# H3_EDGE_LENGTH_M

指定した解像度における六角形の平均辺長をメートル単位で返します。五角形は含まれません。

## 構文 {#syntax}

```sql
H3_EDGE_LENGTH_M(1)
```

## 例 {#examples}

```sql
┌─────────────────────┐
│ h3_edge_length_m(1) │
├─────────────────────┤
│   483056.8390711111 │
└─────────────────────┘
```
