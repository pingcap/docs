# LPAD

文字列 str の左側を文字列 padstr で埋めて、長さ len 文字の文字列を返します。str が len より長い場合、返り値は len 文字に切り詰められます。

## 構文 {#syntax}

```sql
LPAD(<str>, <len>, <padstr>)
```

## 引数 {#arguments}

| 引数 | 説明 |
|------------|-----------------|
| `<str>`    | 文字列です。 |
| `<len>`    | 長さです。 |
| `<padstr>` | 埋め込みに使用する文字列です。 |

## 戻り値の型 {#return-type}

`VARCHAR`

## 例 {#examples}

```sql
SELECT LPAD('hi',4,'??');
+---------------------+
| LPAD('hi', 4, '??') |
+---------------------+
| ??hi                |
+---------------------+

SELECT LPAD('hi',1,'??');
+---------------------+
| LPAD('hi', 1, '??') |
+---------------------+
| h                   |
+---------------------+
```
