# Dictionary

Dictionary は、MySQL や Redis を含むさまざまな外部データソースからデータを読み取るためのキー・バリュー方式を提供します。

## 辞書の管理 {#dictionary-management}

| コマンド | 説明 |
|---------|-------------|
| [CREATE DICTIONARY](/tidb-cloud-lake/sql/create-dictionary.md) | 辞書を作成します |
| [DROP DICTIONARY](/tidb-cloud-lake/sql/drop-dictionary.md) | 辞書を削除します |
| [RENAME DICTIONARY](/tidb-cloud-lake/sql/rename-dictionary.md) | 辞書の名前を変更します |

## 辞書の情報 {#dictionary-information}

| コマンド | 説明 |
|---------|-------------|
| [SHOW CREATE DICTIONARY](/tidb-cloud-lake/sql/show-create-dictionary.md) | 辞書の CREATE 文を表示します |
| [SHOW DICTIONARIES](/tidb-cloud-lake/sql/show-dictionaries.md) | 辞書の一覧を表示します |
