# 字典

字典提供了一种键值方式，用于从各种外部数据源（包括 MySQL 和 Redis）中读数据。

## 字典管理 {#dictionary-management}

| 命令 | 描述 |
|---------|-------------|
| [CREATE DICTIONARY](/tidb-cloud-lake/sql/create-dictionary.md) | 创建字典 |
| [DROP DICTIONARY](/tidb-cloud-lake/sql/drop-dictionary.md) | 删除字典 |
| [RENAME DICTIONARY](/tidb-cloud-lake/sql/rename-dictionary.md) | 重命名字典 |

## 字典信息 {#dictionary-information}

| 命令 | 描述 |
|---------|-------------|
| [SHOW CREATE DICTIONARY](/tidb-cloud-lake/sql/show-create-dictionary.md) | 显示字典的 CREATE 语句 |
| [SHOW DICTIONARIES](/tidb-cloud-lake/sql/show-dictionaries.md) | 列出字典 |
