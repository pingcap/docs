# SHOW STREAMS

特定のデータベースに関連付けられたストリームを一覧表示します。

## 構文 {#syntax}

```sql
SHOW [ FULL ] STREAMS
     [ { FROM | IN } <database_name> ]
     [ LIKE '<pattern>' | WHERE <expr> ]
```

| パラメータ | 説明                                                                                  |
|-----------|---------------------------------------------------------------------------------------|
| FULL      | 追加情報を含めて結果を一覧表示します。詳細は [例](#examples) を参照してください。     |
| FROM / IN | データベースを指定します。省略した場合、このコマンドは現在のデータベースの結果を返します。 |
| LIKE      | `%` ワイルドカードを使用した大文字と小文字を区別するパターンマッチングで、ストリーム名をフィルタリングします。 |
| WHERE     | WHERE 句の式を使用してストリーム名をフィルタリングします。                            |

## 例 {#examples}

次の例は、現在のデータベースに属するストリームを表示します。

```sql
SHOW STREAMS;

┌──────────────────────────────────────────────────────────┐
│ Streams_in_default │        table_on       │     mode    │
├────────────────────┼───────────────────────┼─────────────┤
│ order_changes      │ default.orders        │ append_only │
│ s_append_only      │ default.t_append_only │ append_only │
│ s_standard         │ default.t_standard    │ standard    │
└──────────────────────────────────────────────────────────┘
```
