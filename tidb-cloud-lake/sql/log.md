# LOG10

`x` の常用対数を返します。`x` が 0.0E0 以下の場合、この関数は NULL を返します。

## 構文 {#syntax}

```sql
LOG10( <x> )
```

## 例 {#examples}

```sql
SELECT LOG10(100);

┌────────────┐
│ log10(100) │
├────────────┤
│          2 │
└────────────┘
```
