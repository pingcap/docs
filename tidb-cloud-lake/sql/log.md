# LOG10

返回 `x` 的以 10 为底的对数。如果 `x` 小于或等于 0.0E0，则该函数返回 NULL。

## 语法 {#syntax}

```sql
LOG10( <x> )
```

## 示例 {#examples}

```sql
SELECT LOG10(100);

┌────────────┐
│ log10(100) │
├────────────┤
│          2 │
└────────────┘
```
