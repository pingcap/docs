# VERSION

返回 LakeQuery 的当前版本。

## 语法 {#syntax}

```sql
VERSION()
```

## 示例 {#examples}

```sql
SELECT VERSION();

┌───────────────────────────────────────────────────────────────────────────────────────────────┐
│                                           version()                                           │
├───────────────────────────────────────────────────────────────────────────────────────────────┤
│ LakeQuery v1.2.252-nightly-193ed56304(rust-1.75.0-nightly-2023-12-12T22:07:25.371440000Z) │
└───────────────────────────────────────────────────────────────────────────────────────────────┘
```
