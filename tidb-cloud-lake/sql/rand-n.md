# RAND(n)

範囲 `0 <= v < 1.0` のランダムな浮動小数点値 v を返します。範囲 `i <= R < j` のランダムな整数 R を取得するには、式 `FLOOR(i + RAND() * (j − i))` を使用します。引数 `n` はシード値として使用されます。同じ引数値に対して、RAND(n) は毎回同じ値を返すため、カラム値の再現可能なシーケンスを生成します。

## 構文 {#syntax}

```sql
RAND( <n>)
```

## 例 {#examples}

```sql
SELECT RAND(1);

┌────────────────────┐
│       rand(1)      │
├────────────────────┤
│ 0.7133693869548766 │
└────────────────────┘
```
