# RAND(n)

返回范围 `0 <= v < 1.0` 内的随机 float 值 v。若要获取范围 `i <= R < j` 内的随机整数型 R，请使用表达式 `FLOOR(i + RAND() * (j − i))`。参数 `n` 用作数据填充值。对于相同的参数值，RAND(n) 每次都会返回相同的值，因此会生成可重复的列值序列。

## 语法 {#syntax}

```sql
RAND( <n>)
```

## 示例 {#examples}

```sql
SELECT RAND(1);

┌────────────────────┐
│       rand(1)      │
├────────────────────┤
│ 0.7133693869548766 │
└────────────────────┘
```
