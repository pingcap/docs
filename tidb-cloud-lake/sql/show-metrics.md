# SHOW METRICS

[システムメトリクス](/tidb-cloud-lake/sql/system-metrics.md) の一覧を表示します。

## 構文 {#syntax}

```sql
SHOW METRICS [LIKE '<pattern>' | WHERE <expr>] | [LIMIT <limit>]
```
