# LOG2

`x` の底 2 の対数を返します。`x` が 0.0E0 以下の場合、この関数は NULL を返します。

## 構文 {#syntax}

```sql
LOG2( <x> )
```

## 例 {#examples}

```sql
SELECT LOG2(65536);

┌─────────────┐
│ log2(65536) │
├─────────────┤
│          16 │
└─────────────┘
```
