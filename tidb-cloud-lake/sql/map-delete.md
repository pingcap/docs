# MAP_DELETE

既存の MAP から 1 つ以上のキーを削除して返します。

## 構文 {#syntax}

```sql
MAP_DELETE( <map>, <key1> [, <key2>, ... ] )
MAP_DELETE( <map>, <array> )
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|--------------------------------------------------------|
| `<map>`   | 削除する KEY を含む MAP。               |
| `<keyN>`  | 返される MAP から除外する KEY。          |
| `<array>` | 返される MAP から除外する KEY の配列。 |

> **Note:**
>
> - キー式の型と、map 内のキーの型は同じである必要があります。
> - map 内に存在しないキー値は無視されます。

## 戻り値の型 {#return-type}

Map。

## 例 {#examples}

```sql
SELECT MAP_DELETE({'a':1,'b':2,'c':3}, 'a', 'c');
┌───────────────────────────────────────────┐
│ map_delete({'a':1,'b':2,'c':3}, 'a', 'c') │
├───────────────────────────────────────────┤
│ {'b':2}                                   │
└───────────────────────────────────────────┘

SELECT MAP_DELETE({'a':1,'b':2,'c':3}, ['a', 'b']);
┌─────────────────────────────────────────────┐
│ map_delete({'a':1,'b':2,'c':3}, ['a', 'b']) │
├─────────────────────────────────────────────┤
│ {'c':3}                                     │
└─────────────────────────────────────────────┘
```
