# LOG(b, x)

返回 `x` 以 `b` 为底的对数。如果 `x` 小于或等于 0.0E0，则该函数返回 NULL。

## 语法 {#syntax}

```sql
LOG( <b, x> )
```

## 示例 {#examples}

```sql
SELECT LOG(2, 65536);

┌───────────────┐
│ log(2, 65536) │
├───────────────┤
│            16 │
└───────────────┘
```
