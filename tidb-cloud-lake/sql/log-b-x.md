# LOG(b, x)

`x` の底 `b` の対数を返します。`x` が 0.0E0 以下の場合、この関数は NULL を返します。

## 構文 {#syntax}

```sql
LOG( <b, x> )
```

## 例 {#examples}

```sql
SELECT LOG(2, 65536);

┌───────────────┐
│ log(2, 65536) │
├───────────────┤
│            16 │
└───────────────┘
```
