# LAST_DAY

指定された日付またはタイムスタンプに基づいて、指定した期間（週、月、四半期、または年）の最終日を返します。

## 構文 {#syntax}

```sql
LAST_DAY(<date_expression>, <date_part>)
```

| パラメータ | 説明 |
|---------------------|---------------------------------------------------------------------------------------------------------------|
| `<date_expression>` | 指定した期間の最終日を計算するための DATE または TIMESTAMP 値です。 |
| `<date_part>`       | 最終日を求める date_part です。指定できる値は `week`、`month`、`quarter`、`year` です。 |

## 戻り値の型 {#return-type}

Date。

## 例 {#examples}

任意の日付のトランザクション日付（例: 2024-11-13）に基づいて、常に月末となる請求日を求めたいとします。

```sql
SELECT LAST_DAY(to_date('2024-11-13'), month) AS billing_date;

┌──────────────┐
│ billing_date │
├──────────────┤
│ 2024-11-30   │
└──────────────┘
```
