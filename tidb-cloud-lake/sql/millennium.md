# MILLENNIUM

返回给定日期或时间戳所属的千年。第 1 个千年涵盖 0001–1000 年，第 2 个千年涵盖 1001–2000 年，第 3 个千年涵盖 2001–3000 年，依此类推。

## 语法 {#syntax}

```sql
MILLENNIUM(<date_or_timestamp>)
```

## 返回类型 {#return-type}

UInt8 — 从 1 开始的千年编号。

## 示例 {#examples}

```sql
SELECT
  MILLENNIUM('1992-02-15')       AS millennium_1992,
  MILLENNIUM('2025-04-16 12:34:56')    AS millennium_2025;
```

```sql
┌───────────────────────────────────┐
│ millennium_1992 │ millennium_2025 │
├─────────────────┼─────────────────┤
│               2 │               3 │
└───────────────────────────────────┘
```
