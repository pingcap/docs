# POINT_IN_ELLIPSES

点が指定されたいずれかの楕円の内側にある場合は 1 を返し、それ以外の場合は 0 を返します。各楕円は、中心点と長半径および短半径によって定義されます。

## 構文 {#syntax}

```sql
POINT_IN_ELLIPSES(x, y, x1, y1, a1, b1 [, x2, y2, a2, b2, ...])
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|-------------|
| `x`, `y` | 判定対象の点の座標です。 |
| `x1`, `y1` | 1 つ目の楕円の中心です。 |
| `a1`, `b1` | 1 つ目の楕円の長半径および短半径の長さです。 |
| `x2`, `y2`, `a2`, `b2`, ... | 同じ方法で定義される、追加の楕円（省略可能）です。 |

## 戻り値の型 {#return-type}

UInt8（真の場合は 1、偽の場合は 0）。

## 例 {#examples}

```sql
SELECT POINT_IN_ELLIPSES(10, 10, 10, 9.1, 1, 0.9999) AS inside;

╭────────╮
│ inside │
├────────┤
│      1 │
╰────────╯
```
