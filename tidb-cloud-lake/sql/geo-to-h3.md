# GEO_TO_H3

指定した位置が属する六角形セルの [H3](https://eng.uber.com/h3/) インデックスを返します。0 が返る場合は、エラーが発生したことを意味します。

## 構文 {#syntax}

```sql
GEO_TO_H3(lon, lat, res)
```

## 例 {#examples}

```sql
SELECT GEO_TO_H3(37.79506683, 55.71290588, 15);

┌─────────────────────────────────────────┐
│ geo_to_h3(37.79506683, 55.71290588, 15) │
├─────────────────────────────────────────┤
│                      644325524701193974 │
└─────────────────────────────────────────┘
```
