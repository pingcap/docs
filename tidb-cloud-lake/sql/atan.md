# ATAN

返回 `x` 的反正切值，即正切值为 `x` 的值。

## 语法 {#syntax}

```sql
ATAN( <x> )
```

## 示例 {#examples}

```sql
SELECT ATAN(-2);

┌─────────────────────┐
│     atan((- 2))     │
├─────────────────────┤
│ -1.1071487177940906 │
└─────────────────────┘
```
