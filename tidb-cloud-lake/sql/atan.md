# ATAN

`x` の逆正接、つまり正接が `x` となる値を返します。

## 構文 {#syntax}

```sql
ATAN( <x> )
```

## 例 {#examples}

```sql
SELECT ATAN(-2);

┌─────────────────────┐
│     atan((- 2))     │
├─────────────────────┤
│ -1.1071487177940906 │
└─────────────────────┘
```
