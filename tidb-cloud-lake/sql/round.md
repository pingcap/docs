# ROUND

引数 x を小数点以下 d 桁に丸めます。丸めアルゴリズムは x のデータ型によって異なります。d を指定しない場合のデフォルト値は 0 です。d には負の値を指定でき、その場合は値 x の小数点の左側にある d 桁が 0 になります。d の絶対値の最大値は 30 で、30（または -30）を超える桁は切り捨てられます。

この関数の結果を計算に使用する場合は、戻り値のデータ型が DOUBLE であるため、最終的な精度に影響する可能性があることに注意してください。

```sql
SELECT ROUND(4/7, 4) - ROUND(3/7, 4); -- Result: 0.14280000000000004
SELECT ROUND(4/7, 4)::DECIMAL(8,4) - ROUND(3/7, 4)::DECIMAL(8,4); -- Result: 0.1428
```

## 構文 {#syntax}

```sql
ROUND( <x, d> )
```

## 例 {#examples}

```sql
SELECT ROUND(0.123, 2);

┌─────────────────┐
│ round(0.123, 2) │
├─────────────────┤
│ 0.12            │
└─────────────────┘
```
