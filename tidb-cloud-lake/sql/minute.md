# TO_MINUTE

将带时间的日期（timestamp/datetime）转换为一个 UInt8 数值，表示小时中的分钟数（0-59）。

## 语法 {#syntax}

```sql
TO_MINUTE(<expr>)
```

## 参数 {#arguments}

| 参数 | 描述 |
|-----------|-------------|
| `<expr>`  | 时间戳   |

## 返回类型 {#return-type}

 `TINYINT`

## 示例 {#examples}

```sql
SELECT
    to_minute('2023-11-12 09:38:18.165575');

┌─────────────────────────────────────────┐
│ to_minute('2023-11-12 09:38:18.165575') │
├─────────────────────────────────────────┤
│                                      38 │
└─────────────────────────────────────────┘
```
