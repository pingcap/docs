# ASIN

返回 `x` 的反正弦，即正弦值为 `x` 的值。如果 `x` 不在 -1 到 1 的范围内，则返回 NULL。

## 语法 {#syntax}

```sql
ASIN( <x> )
```

## 示例 {#examples}

```sql
SELECT ASIN(0.2);

┌────────────────────┐
│      asin(0.2)     │
├────────────────────┤
│ 0.2013579207903308 │
└────────────────────┘
```
