# ASIN

`x` の逆正弦、つまり正弦が `x` となる値を返します。`x` が -1 から 1 の範囲外の場合は NULL を返します。

## 構文 {#syntax}

```sql
ASIN( <x> )
```

## 例 {#examples}

```sql
SELECT ASIN(0.2);

┌────────────────────┐
│      asin(0.2)     │
├────────────────────┤
│ 0.2013579207903308 │
└────────────────────┘
```
