# NOT ] IN

値が明示的なリストに含まれているか（または含まれていないか）を確認します。

## 構文 {#syntax}

```sql
<value> [ NOT ] IN (<value1>, <value2> ...)
```

## 例 {#examples}

```sql
SELECT 1 NOT IN (2, 3);

┌────────────────┐
│ 1 not in(2, 3) │
├────────────────┤
│ true           │
└────────────────┘
```
