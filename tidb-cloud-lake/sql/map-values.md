# MAP_VALUES

マップ内の値を返します。

## 構文 {#syntax}

```sql
MAP_VALUES( <map> )
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|----------------|
| `<map>`   | 入力マップ。 |

## 戻り値の型 {#return-type}

Array。

## 例 {#examples}

```sql
SELECT MAP_VALUES({'a':1,'b':2,'c':3});

┌─────────────────────────────────┐
│ map_values({'a':1,'b':2,'c':3}) │
├─────────────────────────────────┤
│ [1,2,3]                         │
└─────────────────────────────────┘
```
