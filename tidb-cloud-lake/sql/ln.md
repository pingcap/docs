# LN

返回 `x` 的自然对数；也就是以 e 为底的 `x` 的对数。如果 x 小于或等于 0.0E0，该函数返回 NULL。

## 语法 {#syntax}

```sql
LN( <x> )
```

## 示例 {#examples}

```sql
SELECT LN(2);

┌────────────────────┐
│        ln(2)       │
├────────────────────┤
│ 0.6931471805599453 │
└────────────────────┘
```
