# LN

`x` の自然対数、つまり `x` の底 e の対数を返します。x が 0.0E0 以下の場合、この関数は NULL を返します。

## 構文 {#syntax}

```sql
LN( <x> )
```

## 例 {#examples}

```sql
SELECT LN(2);

┌────────────────────┐
│        ln(2)       │
├────────────────────┤
│ 0.6931471805599453 │
└────────────────────┘
```
