# NEXT_DAY

指定した日付またはタイムスタンプの後に到来する、指定した曜日の日付を返します。

## 構文 {#syntax}

```sql
NEXT_DAY(<date_expression>, <target_day>)
```

| パラメーター        | 説明                                                                                                                                                           |
|---------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `<date_expression>` | 指定した曜日の次の出現日を計算するための `DATE` または `TIMESTAMP` 値です。                                                                                   |
| `<target_day>`      | 次の出現日を求める対象の曜日です。指定できる値は `monday`、`tuesday`、`wednesday`、`thursday`、`friday`、`saturday`、`sunday` です。 |

## 戻り値の型 {#return-type}

Date。

## 例 {#examples}

2024-11-13 のような特定の日付の次の月曜日を求めるには、次のようにします。

```sql
SELECT NEXT_DAY(to_date('2024-11-13'), monday) AS next_monday;

┌─────────────┐
│ next_monday │
├─────────────┤
│ 2024-11-18  │
└─────────────┘
```
