# NEXT_DAY

返回给定日期或时间戳之后即将到来的指定星期几的日期。

## 语法 {#syntax}

```sql
NEXT_DAY(<date_expression>, <target_day>)
```

| 参数 | 描述 |
|---------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `<date_expression>` | 用于计算指定星期几下一次出现日期的 `DATE` 或 `TIMESTAMP` 值。 |
| `<target_day>`      | 要查找其下一次出现日期的目标星期几。可接受的值包括 `monday`、`tuesday`、`wednesday`、`thursday`、`friday`、`saturday` 和 `sunday`。 |

## 返回类型 {#return-type}

日期。

## 示例 {#examples}

要查找某个特定日期之后的下一个星期一，例如 2024-11-13：

```sql
SELECT NEXT_DAY(to_date('2024-11-13'), monday) AS next_monday;

┌─────────────┐
│ next_monday │
├─────────────┤
│ 2024-11-18  │
└─────────────┘
```
