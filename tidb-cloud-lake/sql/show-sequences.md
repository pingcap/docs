# SHOW SEQUENCES

作成されたシーケンスの一覧を返します。

## 構文 {#syntax}

```sql
SHOW SEQUENCES [ LIKE '<pattern>' | WHERE <expr> ]
```

| パラメータ | 説明 |
|-----------|-----------------------------------------------------------------------------------------------------------------------------|
| LIKE      | 大文字と小文字を区別するパターンマッチングを使用して、名前で結果を絞り込みます。 |
| WHERE     | WHERE 句の式を使用して結果を絞り込みます。`name`、`start`、`interval`、`current`、`created_on`、`updated_on`、`comment` など、結果セット内の任意のカラムに基づいてフィルタできます。例: `WHERE start > 0` または `WHERE name LIKE 's%'`。 |

## 例 {#examples}

```sql
-- Create a sequence
CREATE SEQUENCE seq;

-- Show all sequences
SHOW SEQUENCES;

-- Use the sequence in an INSERT statement
CREATE TABLE tmp(a int, b uint64, c int);
INSERT INTO tmp select 10,nextval(seq),20 from numbers(3);

-- Show sequences after usage
SHOW SEQUENCES;

-- Filter sequences using WHERE clause
SHOW SEQUENCES WHERE start > 0;
```
