# AS_DATE

将 `VARIANT` 值严格转换为 DATE 数据类型。如果输入数据类型不是 `VARIANT`，则输出为 `NULL`。如果 `VARIANT` 中值的类型与输出值不匹配，则输出为 `NULL`。

## 语法 {#syntax}

```sql
AS_DATE( <variant> )
```

## 参数 {#arguments}

| 参数        | 描述 |
|-------------|------|
| `<variant>` | `VARIANT` 值 |

## 返回类型 {#return-type}

DATE

## 示例 {#examples}

```sql
SELECT as_date(to_date('2025-10-11')::variant);
+-----------------------------------------+
| as_date(to_date('2025-10-11')::variant) |
+-----------------------------------------+
| 2025-10-11                              |
+-----------------------------------------+

SELECT as_date(parse_json('"2024-12-25"')::variant);
+-----------------------------------------------+
| as_date(parse_json('"2024-12-25"')::variant) |
+-----------------------------------------------+
| 2024-12-25                                    |
+-----------------------------------------------+

-- 对于非日期值，返回 NULL
SELECT as_date(parse_json('123'));
+----------------------------+
| as_date(parse_json('123')) |
+----------------------------+
| NULL                       |
+----------------------------+
```
