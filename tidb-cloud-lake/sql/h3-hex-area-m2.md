# H3_HEX_AREA_M2

指定した解像度における平均六角形面積を平方メートル単位で返します。五角形は含まれません。

## 構文 {#syntax}

```sql
H3_HEX_AREA_M2(res)
```

## 例 {#examples}

```sql
SELECT H3_HEX_AREA_M2(1);

┌───────────────────┐
│ h3_hex_area_m2(1) │
├───────────────────┤
│ 609788441794.1339 │
└───────────────────┘
```
