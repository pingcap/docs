# 論理演算子

| Operator | 説明 | Example | Result |
|----------|----------------------------------------|---------------|--------|
| **AND**  | 両方の式（`a` と `b`）に一致します | **1 AND 1**   | TRUE   |
| **NOT**  | 式に一致しません | **NOT 1**     | FALSE  |
| **OR**   | いずれかの式に一致します | **1 OR 0**    | TRUE   |
