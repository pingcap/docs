# シーケンス関数

このセクションでは、{{{ .lake }}} のシーケンス関数に関するリファレンス情報を提供します。シーケンス関数を使用すると、一意で自動増分される数値を生成するシーケンスオブジェクトを操作できます。

## 利用可能なシーケンス関数 {#available-sequence-functions}

| 関数 | 説明 | 例 |
|----------|-------------|--------|
| [NEXTVAL](/tidb-cloud-lake/sql/nextval.md) | シーケンスから次の値を取得します | `NEXTVAL(my_sequence)` |
