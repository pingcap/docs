# system.numbers

このテーブルには、number という名前の単一の UInt64 カラムがあり、0 から始まるほぼすべての自然数が含まれています。

このテーブルは、テストや総当たり検索が必要な場合に使用できます。

このテーブルからの読み取りも並列化されます。

テストに使用されます。

```sql
SELECT avg(number) FROM numbers(100000000);
+-------------+
| avg(number) |
+-------------+
|  49999999.5 |
+-------------+
```
