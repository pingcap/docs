# TRUNC

返回数字 `x` 截断到 `d` 位小数后的结果。如果 `d` 为 0，则结果不包含小数点或小数部分。`d` 可以为负数，此时会将 `x` 的小数点左侧的 `d` 位数字变为 0。`d` 的绝对值最大为 30；超过 30（或 -30）的位数会被截断。

如果只提供 `x`，则 `d` 的默认值为 0。

## 语法 {#syntax}

```sql
TRUNC( x [, d] )
```

## 示例 {#examples}

```sql
SELECT TRUNC(1.223, 1);

┌────────────────────┐
│ truncate(1.223, 1) │
├────────────────────┤
│ 1.2                │
└────────────────────┘

SELECT TRUNC(1.223)

╭─────────────────╮
│ truncate(1.223) │
├─────────────────┤
│               1 │
╰─────────────────╯

```
