# TRUNC

数値 `x` を `d` 桁の小数位で切り捨てて返します。`d` が 0 の場合、結果には小数点や小数部は含まれません。`d` には負の値を指定でき、その場合は値 `x` の小数点の左側にある `d` 桁が 0 になります。`d` の絶対値の最大値は 30 で、30（または -30）を超える桁は切り捨てられます。

`x` のみを指定した場合、`d` のデフォルト値は 0 です。

## 構文 {#syntax}

```sql
TRUNC( x [, d] )
```

## 例 {#examples}

```sql
SELECT TRUNC(1.223, 1);

┌────────────────────┐
│ truncate(1.223, 1) │
├────────────────────┤
│ 1.2                │
└────────────────────┘

SELECT TRUNC(1.223)

╭─────────────────╮
│ truncate(1.223) │
├─────────────────╤
│               1 │
╰─────────────────╯

```
