# MAP_CAT

2 つの MAP を連結して返します。

## 構文 {#syntax}

```sql
MAP_CAT( <map1>, <map2> )
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|---------------------------------|
| `<map1>`  | 元の MAP。                 |
| `<map2>`  | map1 に追加される MAP。 |

> **Note:**
>
> - map1 と map2 の両方に同じキーの値がある場合、出力される map には map2 の値が含まれます。
> - いずれかの引数が NULL の場合、この関数はエラーを報告せずに NULL を返します。

## 戻り値の型 {#return-type}

Map。

## 例 {#examples}

```sql
SELECT MAP_CAT({'a':1,'b':2,'c':3}, {'c':5,'d':6});
┌─────────────────────────────────────────────┐
│ map_cat({'a':1,'b':2,'c':3}, {'c':5,'d':6}) │
├─────────────────────────────────────────────┤
│ {'a':1,'b':2,'c':5,'d':6}                   │
└─────────────────────────────────────────────┘
```
