# MAP_CAT

返回两个 MAP 的拼接结果。

## 语法 {#syntax}

```sql
MAP_CAT( <map1>, <map2> )
```

## 参数 {#arguments}

| 参数 | 描述 |
|-----------|---------------------------------|
| `<map1>`  | 源 MAP。                 |
| `<map2>`  | 要追加到 map1 的 MAP。 |

> **注意：**
>
> - 如果 map1 和 map2 都包含相同的键，则输出的 map 包含 map2 中的值。
> - 如果任一参数为 NULL，则该函数返回 NULL，且不会报告任何错误。

## 返回类型 {#return-type}

Map。

## 示例 {#examples}

```sql
SELECT MAP_CAT({'a':1,'b':2,'c':3}, {'c':5,'d':6});
┌─────────────────────────────────────────────┐
│ map_cat({'a':1,'b':2,'c':3}, {'c':5,'d':6}) │
├─────────────────────────────────────────────┤
│ {'a':1,'b':2,'c':5,'d':6}                   │
└─────────────────────────────────────────────┘
```
