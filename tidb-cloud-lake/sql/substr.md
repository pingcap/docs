# SUBSTR

指定された文字列の特定の位置から、指定した文字数を含む文字列を抽出します。

- `len` 引数なしの形式は、文字列 `str` の位置 `pos` から始まる部分文字列を返します。
- `len` 引数ありの形式は、文字列 `str` の位置 `pos` から始まる、長さ `len` 文字の部分文字列を返します。

`pos` には負の値を使用することもできます。この場合、部分文字列の開始位置は文字列の先頭からではなく、文字列の末尾から `pos` 文字分の位置になります。負の値は、この関数のどの形式でも `pos` に使用できます。`pos` に 0 を指定すると空文字列が返されます。部分文字列の抽出元となる文字列の最初の文字位置は 1 として数えられます。

## 構文 {#syntax}

```sql
SUBSTR(<str>, <pos>)

SUBSTR(<str>, <pos>, <len>)
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|--------------------------------------------------------------------------------------------|
| `<str>`   | 文字を抽出する元の文字列 |
| `<pos>`   | 部分文字列の開始位置（1 から開始）。負の値の場合は末尾から数えます |
| `<len>`   | 抽出する部分文字列の最大長 |

## エイリアス {#aliases}

- [SUBSTRING](/tidb-cloud-lake/sql/substring.md)
- [MID](/tidb-cloud-lake/sql/mid.md)

## 戻り値の型 {#return-type}

VARCHAR

## 例 {#examples}

```sql
SELECT
  SUBSTRING('Quadratically', 5),
  SUBSTR('Quadratically', 5),
  MID('Quadratically', 5);

┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
│ substring('quadratically' from 5) │ substring('quadratically' from 5) │ mid('quadratically', 5) │
├───────────────────────────────────┼───────────────────────────────────┼─────────────────────────┤
│ ratically                         │ ratically                         │ ratically               │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘

SELECT
  SUBSTRING('Quadratically', 5, 6),
  SUBSTR('Quadratically', 5, 6),
  MID('Quadratically', 5, 6);

┌────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ substring('quadratically' from 5 for 6) │ substring('quadratically' from 5 for 6) │ mid('quadratically', 5, 6) │
├─────────────────────────────────────────┼─────────────────────────────────────────┼────────────────────────────┤
│ ratica                                  │ ratica                                  │ ratica                     │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```
