# ST_GEOMFROMGEOHASH

[geohash](https://en.wikipedia.org/wiki/Geohash) の境界を表すポリゴンに対応する GEOMETRY オブジェクトを返します。

## 構文 {#syntax}

```sql
ST_GEOMFROMGEOHASH(<geohash>)
```

## 引数 {#arguments}

| 引数 | 説明 |
|-------------|---------------------------------|
| `<geohash>` | 引数は geohash である必要があります。 |

## 戻り値の型 {#return-type}

Geometry。

## 例 {#examples}

```sql
SELECT
  ST_GEOMFROMGEOHASH(
    '9q60y60rhs'
  ) AS pipeline_geometry;
```
