# REGEXP_REPLACE

文字列 `expr` 内で、パターン `pat` で指定された正規表現に一致する箇所を置換文字列 `repl` に置き換え、結果の文字列を返します。`expr`、`pat`、または `repl` が NULL の場合、戻り値は NULL です。

## 構文 {#syntax}

```sql
REGEXP_REPLACE(<expr>, <pat>, <repl[, pos[, occurrence[, match_type]]]>)
```

## 引数 {#arguments}

| 引数       | 説明                                                                                                                    |
|------------|-------------------------------------------------------------------------------------------------------------------------|
| expr       | 一致対象となる文字列 `expr`                                                                                             |
| pat        | 正規表現                                                                                                                |
| repl       | 置換文字列                                                                                                              |
| pos        | 任意。検索を開始する expr 内の位置です。省略した場合のデフォルト値は 1 です。                                           |
| occurrence | 任意。置換する一致箇所が何番目のものかを指定します。省略した場合のデフォルト値は 0 です（これは「すべての一致箇所を置換する」ことを意味します）。 |
| match_type | 任意。マッチングの実行方法を指定する文字列です。意味は REGEXP_LIKE() の説明と同じです。                                |

## 戻り値の型 {#return-type}

`VARCHAR`

## 例 {#examples}

```sql
SELECT REGEXP_REPLACE('a b c', 'b', 'X');
+-----------------------------------+
| REGEXP_REPLACE('a b c', 'b', 'X') |
+-----------------------------------+
| a X c                             |
+-----------------------------------+

SELECT REGEXP_REPLACE('abc def ghi', '[a-z]+', 'X', 1, 3);
+----------------------------------------------------+
| REGEXP_REPLACE('abc def ghi', '[a-z]+', 'X', 1, 3) |
+----------------------------------------------------+
| abc def X                                          |
+----------------------------------------------------+

SELECT REGEXP_REPLACE('周 周周 周周周', '周+', 'X', 3, 2);
+-----------------------------------------------------------+
| REGEXP_REPLACE('周 周周 周周周', '周+', 'X', 3, 2)        |
+-----------------------------------------------------------+
| 周 周周 X                                                 |
+-----------------------------------------------------------+
```
