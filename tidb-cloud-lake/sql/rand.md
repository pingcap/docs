# RAND()

範囲 `0 <= v < 1.0` のランダムな浮動小数点値 v を返します。範囲 `i <= R < j` のランダムな整数 R を取得するには、式 `FLOOR(i + RAND() * (j − i))` を使用します。

## 構文 {#syntax}

```sql
RAND()
```

## 例 {#examples}

```sql
SELECT RAND();

┌────────────────────┐
│       rand()       │
├────────────────────┤
│ 0.5191511074382174 │
└────────────────────┘
```
