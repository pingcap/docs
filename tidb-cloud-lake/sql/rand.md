# RAND()

返回范围 `0 <= v < 1.0` 内的随机 float 值 v。要获取范围 `i <= R < j` 内的随机整数型 R，请使用表达式 `FLOOR(i + RAND() * (j − i))`。

## 语法 {#syntax}

```sql
RAND()
```

## 示例 {#examples}

```sql
SELECT RAND();

┌────────────────────┐
│       rand()       │
├────────────────────┤
│ 0.5191511074382174 │
└────────────────────┘
```
