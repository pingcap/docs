# ST_DWITHIN

返回两个 GEOMETRY 对象是否位于指定的欧几里得距离之内；如果是，则返回 TRUE。

该函数仅支持 GEOMETRY 值。

## 语法 {#syntax}

```sql
ST_DWITHIN(<geometry1>, <geometry2>, <distance>)
```

## 参数 {#arguments}

| 参数          | 描述                                                                 |
|---------------|----------------------------------------------------------------------|
| `<geometry1>` | 该参数必须是 GEOMETRY 类型的表达式。                                 |
| `<geometry2>` | 该参数必须是 GEOMETRY 类型的表达式。                                 |
| `<distance>`  | 最大欧几里得距离，必须是与 Float64 兼容的值。                        |

> **注意：**
>
> 如果两个输入的 GEOMETRY 对象具有不同的 SRID，该函数会报错。

## 返回类型 {#return-type}

Boolean。

## 示例 {#examples}

