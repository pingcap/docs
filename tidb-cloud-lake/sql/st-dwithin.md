# ST_DWITHIN

2 つの GEOMETRY オブジェクトが、指定されたユークリッド距離内にある場合に TRUE を返します。

この関数は GEOMETRY 値のみをサポートします。

## 構文 {#syntax}

```sql
ST_DWITHIN(<geometry1>, <geometry2>, <distance>)
```

## 引数 {#arguments}

| 引数     | 説明                                                  |
|---------------|--------------------------------------------------------------|
| `<geometry1>` | この引数は GEOMETRY 型の式である必要があります。       |
| `<geometry2>` | この引数は GEOMETRY 型の式である必要があります。       |
| `<distance>`  | Float64 と互換性のある値として指定する、最大ユークリッド距離です。 |

> **Note:**
>
> 2 つの入力 GEOMETRY オブジェクトの SRID が異なる場合、この関数はエラーを報告します。

## 戻り値の型 {#return-type}

Boolean。

## 例 {#examples}

