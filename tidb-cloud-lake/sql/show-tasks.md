# SHOW TASKS

現在のロールから参照可能なタスクを一覧表示します。

**NOTICE:** このコマンドは、{{{ .lake }}} でのみそのまま利用できます。セルフホスト環境では、タスクをクエリできるように Cloud Control を設定してください。

## Syntax {#syntax}

```sql
SHOW TASKS [LIKE '<pattern>' | WHERE <expr>]
```

| パラメータ | 説明 |
|-----------|-------------|
| LIKE      | `%` ワイルドカードを使用した大文字小文字を区別するパターンマッチングで、タスク名を絞り込みます。 |
| WHERE     | 出力カラムに対する式を使用して結果セットを絞り込みます。               |

### Output {#output}

`SHOW TASKS` は次のカラムを返します。

- `created_on`: タスクが作成された時刻のタイムスタンプ。
- `name`: タスク名。
- `id`: 内部タスク識別子。
- `owner`: タスクを所有するロール。
- `comment`: 任意のコメント。
- `warehouse`: タスクに割り当てられた Warehouse。
- `schedule`: 存在する場合、実行間隔または CRON スケジュール。
- `state`: 現在の状態（`Started` または `Suspended`）。
- `definition`: タスクが実行する SQL。
- `condition_text`: タスクの WHEN 条件。
- `after`: DAG 内の上流タスクのカンマ区切りリスト。
- `suspend_task_after_num_failures`: 一時停止されるまでの連続失敗回数。
- `error_integration`: 失敗時の通知インテグレーション。
- `next_schedule_time`: 次回のスケジュール実行時刻のタイムスタンプ。
- `last_committed_on`: タスク定義が最後に更新された時刻のタイムスタンプ。
- `last_suspended_on`: タスクが最後に一時停止された時刻のタイムスタンプ。存在する場合。
- `session_parameters`: タスク実行時に適用されるセッションパラメータ。

名前が `ingest_` で始まるタスクのみを表示します。

```sql
SHOW TASKS LIKE 'ingest_%';
```
