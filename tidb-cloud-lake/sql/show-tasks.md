# SHOW TASKS

列出当前角色可见的任务。

**NOTICE:** 此命令开箱即用仅适用于 {{{ .lake }}}。对于自托管部署，请配置 Cloud Control 以查询任务。

## 语法 {#syntax}

```sql
SHOW TASKS [LIKE '<pattern>' | WHERE <expr>]
```

| 参数 | 描述 |
|-----------|-------------|
| LIKE      | 使用大小写敏感的模式匹配和 `%` 通配符过滤任务名称。 |
| WHERE     | 使用输出列上的表达式过滤结果集。               |

### 输出 {#output}

`SHOW TASKS` 返回以下列：

- `created_on`：任务创建时的时间戳。
- `name`：任务名称。
- `id`：内部任务标识符。
- `owner`：拥有该任务的角色。
- `comment`：可选注释。
- `warehouse`：分配给任务的计算集群 (Warehouse)。
- `schedule`：间隔或 CRON 调度（如果存在）。
- `state`：当前状态（`Started` 或 `Suspended`）。
- `definition`：任务运行的 SQL。
- `condition_text`：任务的 WHEN 条件。
- `after`：DAG 中上游任务的逗号分隔列表。
- `suspend_task_after_num_failures`：挂起前允许连续失败的次数。
- `error_integration`：失败时使用的通知集成。
- `next_schedule_time`：下一次计划运行的时间戳。
- `last_committed_on`：上次修改任务定义时的时间戳。
- `last_suspended_on`：任务上次被挂起时的时间戳（如果有）。
- `session_parameters`：任务运行时应用的会话参数。
