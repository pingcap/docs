# ACOS

`x` のアークコサイン、つまりコサインが `x` となる値を返します。`x` が -1 から 1 の範囲外の場合は NULL を返します。

## 構文 {#syntax}

```sql
ACOS( <x> )
```

## 例 {#examples}

```sql
SELECT ACOS(1);

┌─────────┐
│ acos(1) │
├─────────┤
│       0 │
└─────────┘
```
