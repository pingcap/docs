# 外部函数

本页按功能分类，全面概述了 {{{ .lake }}} 中的外部函数操作，便于参考。

## 外部函数管理 {#external-function-management}

| 命令 | 描述 |
|---------|-------------|
| [CREATE EXTERNAL FUNCTION](/tidb-cloud-lake/sql/create-function.md) | 创建新的外部函数 |
| [ALTER EXTERNAL FUNCTION](/tidb-cloud-lake/sql/alter-function-sql.md) | 修改现有的外部函数 |
| [DROP EXTERNAL FUNCTION](/tidb-cloud-lake/sql/drop-function-sql.md) | 删除外部函数 |

> **注意：**
>
> {{{ .lake }}} 中的外部函数允许你通过 HTTP/HTTPS 端点与外部服务集成来扩展功能，从而利用外部处理能力。
