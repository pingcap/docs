# SHOW ROLES

現在のユーザーに割り当てられているすべてのロールを一覧表示します。

## 構文 {#syntax}

```sql
SHOW ROLES
```

## 出力 {#output}

このコマンドは、次のカラムを持つテーブル形式で結果を返します。

| カラム          | 説明                                                         |
|-----------------|--------------------------------------------------------------|
| name            | ロール名。                                                   |
| inherited_roles | 現在のロールが継承しているロール数。                         |
| is_current      | そのロールが現在アクティブかどうかを示します。               |
| is_default      | そのロールがユーザーのデフォルトロールかどうかを示します。   |

## 例 {#examples}

```sql
SHOW ROLES;

┌───────────────────────────────────────────────────────┐
│    name   │ inherited_roles │ is_current │ is_default │
├───────────┼─────────────────┼────────────┼────────────┤
│ developer │               0 │ false      │ false      │
│ public    │               0 │ false      │ false      │
│ writer    │               0 │ true       │ true       │
└───────────────────────────────────────────────────────┘
```
