# TO_START_OF_QUARTER

将日期或带时间的日期（timestamp/datetime）向下舍入到该季度的第一天。季度的第一天可以是 1 月 1 日、4 月 1 日、7 月 1 日或 10 月 1 日。返回日期。

## 语法 {#syntax}

```sql
TO_START_OF_QUARTER(<expr>)
```

## 参数 {#arguments}

| 参数 | 描述 |
|-----------|----------------|
| `<expr>`   | 日期/时间戳 |

## 返回类型 {#return-type}

`DATE`，以 “YYYY-MM-DD” 格式返回日期。

## 示例 {#examples}

```sql
SELECT
  to_start_of_quarter('2023-11-12 09:38:18.165575');

┌───────────────────────────────────────────────────┐
│ to_start_of_quarter('2023-11-12 09:38:18.165575') │
├───────────────────────────────────────────────────┤
│ 2023-10-01                                        │
└───────────────────────────────────────────────────┘
```
