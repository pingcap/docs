# SHA2

SHA-2 ファミリーのハッシュ関数（SHA-224、SHA-256、SHA-384、SHA-512）を計算します。ハッシュ長が許可された値のいずれでもない場合、戻り値は NULL です。それ以外の場合、この関数の結果は、必要なビット数を含むハッシュ値を16進数の文字列として返します。

## 構文 {#syntax}

```sql
SHA2(<expr>, <expr>)
```

## 例 {#examples}

```sql
SELECT SHA2('1234567890', 0);

┌──────────────────────────────────────────────────────────────────┐
│                       sha2('1234567890', 0)                      │
├──────────────────────────────────────────────────────────────────┤
│ c775e7b757ede630cd0aa1113bd102661ab38829ca52a6422ab782862f268646 │
└──────────────────────────────────────────────────────────────────┘
```
