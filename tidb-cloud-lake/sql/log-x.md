# LOG(x)

`x` の自然対数を返します。x が 0.0E0 以下の場合、この関数は NULL を返します。

## 構文 {#syntax}

```sql
LOG( <x> )
```

## 例 {#examples}

```sql
SELECT LOG(2);

┌────────────────────┐
│       log(2)       │
├────────────────────┤
│ 0.6931471805599453 │
└────────────────────┘
```
