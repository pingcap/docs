# LOG(x)

返回 `x` 的自然对数。如果 x 小于或等于 0.0E0，则该函数返回 NULL。

## 语法 {#syntax}

```sql
LOG( <x> )
```

## 示例 {#examples}

```sql
SELECT LOG(2);

┌────────────────────┐
│       log(2)       │
├────────────────────┤
│ 0.6931471805599453 │
└────────────────────┘
```
