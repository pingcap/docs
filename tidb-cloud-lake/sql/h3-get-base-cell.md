# H3_GET_BASE_CELL

指定された [H3](https://eng.uber.com/h3/) インデックスのベースセル番号を返します。

## 構文 {#syntax}

```sql
H3_GET_BASE_CELL(h3)
```

## 例 {#examples}

```sql
SELECT H3_GET_BASE_CELL(644325524701193974);

┌──────────────────────────────────────┐
│ h3_get_base_cell(644325524701193974) │
├──────────────────────────────────────┤
│                                    8 │
└──────────────────────────────────────┘
```
