# DROP NETWORK POLICY

{{{ .lake }}} から既存のネットワークポリシーを削除します。ネットワークポリシーを削除すると、そのポリシーは {{{ .lake }}} から削除され、関連付けられている許可 IP アドレスリストおよびブロック IP アドレスリストのルールは無効になります。ネットワークポリシーを削除する前に、このポリシーがどのユーザーにも関連付けられていないことを確認してください。

## 構文 {#syntax}

```sql
DROP NETWORK POLICY [ IF EXISTS ] <policy_name>
```

## 例 {#examples}

```sql
DROP NETWORK POLICY test_policy
```
