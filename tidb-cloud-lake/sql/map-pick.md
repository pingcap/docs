# MAP_PICK

既存の MAP から指定したキーと値のペアを含む新しい MAP を返します。

## 構文 {#syntax}

```sql
MAP_PICK( <map>, <key1> [, <key2>, ... ] )
MAP_PICK( <map>, <array> )
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|-------------------------------------------------------- |
| `<map>`   | 入力 MAP。 |
| `<keyN>`  | 返される MAP に含める KEY。 |
| `<array>` | 返される MAP に含める KEY の配列。 |

> **Note:**
>
> - キー式の型と、map 内のキーの型は同じである必要があります。
> - map 内に見つからないキー値は無視されます。

## 戻り値の型 {#return-type}

Map。

## 例 {#examples}

```sql
SELECT MAP_PICK({'a':1,'b':2,'c':3}, 'a', 'c');
┌─────────────────────────────────────────┐
│ map_pick({'a':1,'b':2,'c':3}, 'a', 'c') │
├─────────────────────────────────────────┤
│ {'a':1,'c':3}                           │
└─────────────────────────────────────────┘

SELECT MAP_PICK({'a':1,'b':2,'c':3}, ['a', 'b']);
┌───────────────────────────────────────────┐
│ map_pick({'a':1,'b':2,'c':3}, ['a', 'b']) │
├───────────────────────────────────────────┤
│ {'a':1,'b':2}                             │
└───────────────────────────────────────────┘
```
