# MAP_PICK

返回一个新的 MAP，其中包含现有 MAP 中指定的键值对。

## 语法 {#syntax}

```sql
MAP_PICK( <map>, <key1> [, <key2>, ... ] )
MAP_PICK( <map>, <array> )
```

## 参数 {#arguments}

| 参数 | 描述 |
|-----------|-------------------------------------------------------- |
| `<map>`   | 输入的 MAP。                                          |
| `<keyN>`  | 返回的 MAP 中要包含的 KEY。          |
| `<array>` | 返回的 MAP 中要包含的 KEY 数组。 |

> **注意：**
>
> - 键表达式的类型必须与 map 中键的类型相同。
> - 在 map 中找不到的键值将被忽略。

## 返回类型 {#return-type}

Map。

## 示例 {#examples}

```sql
SELECT MAP_PICK({'a':1,'b':2,'c':3}, 'a', 'c');
┌─────────────────────────────────────────┐
│ map_pick({'a':1,'b':2,'c':3}, 'a', 'c') │
├─────────────────────────────────────────┤
│ {'a':1,'c':3}                           │
└─────────────────────────────────────────┘

SELECT MAP_PICK({'a':1,'b':2,'c':3}, ['a', 'b']);
┌───────────────────────────────────────────┐
│ map_pick({'a':1,'b':2,'c':3}, ['a', 'b']) │
├───────────────────────────────────────────┤
│ {'a':1,'b':2}                             │
└───────────────────────────────────────────┘
```
