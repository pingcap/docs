# SHOW TABLE STATUS

データベース内のテーブルのステータスを表示します。ステータス情報には、テーブルに関するさまざまな物理サイズやタイムスタンプが含まれます。詳細は[例](#examples)を参照してください。

## 構文 {#syntax}

```sql
SHOW TABLE STATUS
    [ {FROM | IN} <database_name> ]
    [ LIKE 'pattern' | WHERE expr ]
```

| パラメーター | 説明 |
|-----------|-----------------------------------------------------------------------------------------------------------------------------|
| FROM / IN | データベースを指定します。省略した場合、このコマンドは現在のデータベースの結果を返します。 |
| LIKE      | 大文字と小文字を区別するパターンマッチングを使用して、テーブル名で結果を絞り込みます。 |
| WHERE     | WHERE 句の式を使用して結果を絞り込みます。 |

## 例 {#examples}

次の例では、現在のデータベース内のテーブルのステータスを表示し、名前、エンジン、行数、その他の関連情報などの詳細を確認できます。

次の例では、現在のデータベース内で名前が `'my'` で始まるテーブルのステータスを表示します。

```sql
SHOW TABLE STATUS LIKE 'my%';

name   |engine|version|row_format|rows|avg_row_length|data_length|max_data_length|index_length|data_free|auto_increment|create_time                  |update_time|check_time|collation|checksum|comment|cluster_by|

```

次の例では、現在のデータベース内で行数が 100 を超えるテーブルのステータスを表示します。

> **Note:**
>
> SHOW TABLE STATUS クエリを使用する際は、`rows` などの一部のカラム名が SQL キーワードとして解釈され、エラーの原因になる可能性があることに注意してください。この問題を回避するには、この例のようにカラム名を常にバッククォートで囲んでください。これにより、SQL クエリ内でカラム名がキーワードではなく識別子として扱われます。

```sql
SHOW TABLE STATUS WHERE `rows` > 100;

name  |engine|version|row_format|rows|avg_row_length|data_length|max_data_length|index_length|data_free|auto_increment|create_time                  |update_time|check_time|collation|checksum|comment|cluster_by|
------+------+-------+----------+----+--------------+-----------+---------------+------------+---------+--------------+-----------------------------+-----------+----------+---------+--------+-------+----------+
ontime|FUSE  |      0|          | 199|              |     147981|               |       22961|         |              |2023-09-19 07:04:06.414 +0000|           |          |         |        |       |          |
```
