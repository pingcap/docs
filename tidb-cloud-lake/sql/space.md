# SPACE

N 個の空白文字からなる文字列を返します。

## 構文 {#syntax}

```sql
SPACE(<n>);
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|----------------------|
| `<n>`     | 空白の数 |

## 戻り値の型 {#return-type}

文字列データ型の値です。

## 例 {#examples}

```sql
SELECT SPACE(20)
+----------------------+
| SPACE(20)            |
+----------------------+
|                      |
+----------------------+
```
