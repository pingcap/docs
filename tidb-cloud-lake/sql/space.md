# SPACE

返回一个由 N 个空格字符组成的字符串。

## 语法 {#syntax}

```sql
SPACE(<n>);
```

## 参数 {#arguments}

| 参数 | 描述 |
|-----------|----------------------|
| `<n>`     | 空格的数量 |

## 返回类型 {#return-type}

字符串数据类型值。

## 示例 {#examples}

```sql
SELECT SPACE(20)
+----------------------+
| SPACE(20)            |
+----------------------+
|                      |
+----------------------+
```
