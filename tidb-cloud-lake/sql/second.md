# TO_SECOND

将带时间的日期（timestamp/datetime）转换为一个 UInt8 数字，表示分钟中的秒数（0-59）。

## 语法 {#syntax}

```sql
TO_SECOND(<expr>)
```

## 参数 {#arguments}

| 参数 | 描述 |
|-----------|-------------|
| `<expr>`  | 时间戳   |

## 返回类型 {#return-type}

`TINYINT`

## 示例 {#examples}

```sql
SELECT
    to_second('2023-11-12 09:38:18.165575');

┌─────────────────────────────────────────┐
│ to_second('2023-11-12 09:38:18.165575') │
├─────────────────────────────────────────┤
│                                      18 │
└─────────────────────────────────────────┘
```
