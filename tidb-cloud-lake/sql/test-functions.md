# テスト関数

このページでは、{{{ .lake }}} のテスト関数に関するリファレンス情報を提供します。これらの関数は主にテストおよびデバッグ目的で使用されます。

## 利用可能なテスト関数 {#available-test-functions}

| 関数 | 説明 | 例 |
|----------|-------------|--------|
| [SLEEP](/tidb-cloud-lake/sql/sleep.md) | 指定した秒数だけ実行を一時停止します | `SELECT SLEEP(2)` → `0` |
