# PARSE_JSON

`parse_json` と `try_parse_json` は、入力文字列を JSON ドキュメントとして解釈し、VARIANT 値を生成します。

`try_parse_json` は、解析中にエラーが発生した場合に NULL 値を返します。

## 構文 {#syntax}

```sql
PARSE_JSON(<expr>)
TRY_PARSE_JSON(<expr>)
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|--------------------------------------------------------------------------------|
| `<expr>`  | 有効な JSON 情報を保持する文字列型（例: VARCHAR）の式です。 |

## 戻り値の型 {#return-type}

VARIANT

## 例 {#examples}

```sql
SELECT parse_json('[-1, 12, 289, 2188, false]');
+------------------------------------------+
| parse_json('[-1, 12, 289, 2188, false]') |
+------------------------------------------+
| [-1,12,289,2188,false]                   |
+------------------------------------------+

SELECT try_parse_json('{ "x" : "abc", "y" : false, "z": 10} ');
+---------------------------------------------------------+
| try_parse_json('{ "x" : "abc", "y" : false, "z": 10} ') |
+---------------------------------------------------------+
| {"x":"abc","y":false,"z":10}                            |
+---------------------------------------------------------+
```
