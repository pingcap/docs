# 比較演算子

| 演算子 | 説明 | 例 | 結果 |
| ------------- | ------------------------------------------- | ------------------------- | ------ |
| `=`           | a が b と等しい                             | `2 = 2`                   | TRUE   |
| `!=`          | a が b と等しくない                         | `2 != 3`                  | TRUE   |
| `<>`         | a が b と等しくない                         | `2 <> 2`                 | FALSE  |
| `>`           | a が b より大きい                           | `2 > 3`                   | FALSE  |
| `>=`          | a が b 以上である                           | `4 >= NULL`               | NULL   |
| `<`           | a が b より小さい                           | `2 < 3`                   | TRUE   |
| `<=`          | a が b 以下である                           | `2 <= 3`                  | TRUE   |
| `IS NULL`     | 式が NULL の場合は TRUE、それ以外は FALSE   | `(4 >= NULL) IS NULL`     | TRUE   |
| `IS NOT NULL` | 式が NULL の場合は FALSE、それ以外は TRUE   | `(4 >= NULL) IS NOT NULL` | FALSE  |
