# TO_STRING

将值转换为 String 数据类型，或将 Date 值转换为特定的字符串格式。要在 {{{ .lake }}} 中自定义日期和时间的格式，可以使用格式说明符。这些说明符可让你定义日期和时间值的所需格式。有关支持的说明符完整列表，请参见 [格式化日期和时间](/tidb-cloud-lake/sql/date-time.md#formatting-date-and-time)。

## 语法 {#syntax}

```sql
TO_STRING( '<expr>' )

TO_STRING( '<date>', '<format>' )
```

## 日期格式样式 {#date-format-styles}

{{{ .lake }}} 支持两种日期格式样式，可通过 `date_format_style` 设置进行选择：

- **MySQL**（默认）：使用与 MySQL 兼容的格式说明符，例如 `%Y`、`%m`、`%d` 等。
- **Oracle**：使用 `YYYY`、`MM`、`DD` 等格式说明符，这些说明符遵循许多数据库系统中常用的标准化格式。

要在不同格式样式之间切换，请使用 `date_format_style` 设置：

```sql
-- Set Oracle-style date format
SETTINGS (date_format_style = 'Oracle') SELECT to_string('2024-04-05'::DATE, 'YYYY-MM-DD');

-- Set MySQL date format style (default)
SETTINGS (date_format_style = 'MySQL') SELECT to_string('2024-04-05'::DATE, '%Y-%m-%d');
```

### Oracle 风格格式说明符 {#oracle-style-format-specifiers}

当 `date_format_style` 设置为 'Oracle' 时，支持以下格式说明符：

| 格式说明符 | 描述 | 示例输出（针对 '2024-04-05 14:30:45.123456'） |
|------------------|----------------------------------------------|---------------------------------------------------|
| YYYY             | 4 位年份                                     | 2024                                              |
| YY               | 2 位年份                                     | 24                                                |
| MMMM             | 完整月份名称                                 | April                                             |
| MON              | 月份简称                                     | Apr                                               |
| MM               | 月份数字 (01-12)                             | 04                                                |
| DD               | 月内日期 (01-31)                             | 05                                                |
| DY               | 星期简称                                     | Fri                                               |
| HH24             | 小时 (00-23)                                 | 14                                                |
| HH12             | 小时 (01-12)                                 | 02                                                |
| AM/PM            | 上下午指示符                                 | PM                                                |
| MI               | 分钟 (00-59)                                 | 30                                                |
| SS               | 秒 (00-59)                                   | 45                                                |
| FF               | 小数秒                                       | 123456                                            |
| UUUU             | ISO 周编号年份                               | 2024                                              |
| TZH:TZM          | 带冒号的时区小时和分钟                       | +08:00                                            |
| TZH              | 时区小时                                     | +08                                               |

## 返回类型 {#return-type}

String。
