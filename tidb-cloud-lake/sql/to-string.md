# TO_STRING

値を String データ型に変換するか、Date 値を特定の文字列形式に変換します。{{{ .lake }}} で日付と時刻の形式をカスタマイズするには、specifier を使用できます。これらの specifier により、日付および時刻の値に対して必要な形式を定義できます。サポートされている specifier の一覧については、[日付と時刻の書式設定](/tidb-cloud-lake/sql/date-time.md#formatting-date-and-time) を参照してください。

## 構文 {#syntax}

```sql
TO_STRING( '<expr>' )

TO_STRING( '<date>', '<format>' )
```

## 日付形式のスタイル {#date-format-styles}

{{{ .lake }}} は、`date_format_style` 設定を使用して選択できる 2 つの日付形式スタイルをサポートしています。

- **MySQL** (default): `%Y`、`%m`、`%d` などの MySQL 互換の形式指定子を使用します。
- **Oracle**: `YYYY`、`MM`、`DD` などの形式指定子を使用します。これらは、多くのデータベースシステムで一般的に使用される標準化された形式に従っています。

形式スタイルを切り替えるには、`date_format_style` 設定を使用します。

```sql
-- Set Oracle-style date format
SETTINGS (date_format_style = 'Oracle') SELECT to_string('2024-04-05'::DATE, 'YYYY-MM-DD');

-- Set MySQL date format style (default)
SETTINGS (date_format_style = 'MySQL') SELECT to_string('2024-04-05'::DATE, '%Y-%m-%d');
```

### Oracle スタイルの形式指定子 {#oracle-style-format-specifiers}

`date_format_style` が 'Oracle' に設定されている場合、次の形式指定子がサポートされます。

| 形式指定子 | 説明 | 出力例（'2024-04-05 14:30:45.123456' の場合） |
|------------------|----------------------------------------------|---------------------------------------------------|
| YYYY             | 4 桁の年                                 | 2024                                              |
| YY               | 2 桁の年                                 | 24                                                |
| MMMM             | 月の完全名                              | April                                             |
| MON              | 月の省略名                       | Apr                                               |
| MM               | 月番号 (01-12)                         | 04                                                |
| DD               | 日 (01-31)                         | 05                                                |
| DY               | 曜日の省略名                         | Fri                                               |
| HH24             | 時 (00-23)                          | 14                                                |
| HH12             | 時 (01-12)                          | 02                                                |
| AM/PM            | 午前/午後インジケーター                           | PM                                                |
| MI               | 分 (00-59)                               | 30                                                |
| SS               | 秒 (00-59)                               | 45                                                |
| FF               | 小数秒                           | 123456                                            |
| UUUU             | ISO 週番号ベースの年                      | 2024                                              |
| TZH:TZM          | コロン付きのタイムゾーン時・分         | +08:00                                            |
| TZH              | タイムゾーンの時                               | +08                                               |

## エイリアス {#aliases}

- [DATE_FORMAT](/tidb-cloud-lake/sql/date-format.md)
- [JSON_TO_STRING](/tidb-cloud-lake/sql/json-to-string.md)
- [TO_TEXT](/tidb-cloud-lake/sql/to-text.md)
- [TO_VARCHAR](/tidb-cloud-lake/sql/to-varchar.md)
- TO_CHAR (Oracle compatibility)

## 戻り値の型 {#return-type}

String。
