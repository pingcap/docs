# UNSET

将一个或多个系统设置恢复为其全局或默认级别及值。有关设置级别的更多信息，请参阅 [设置级别](/tidb-cloud-lake/sql/show-settings.md#setting-levels)。要显示所有当前设置，请使用 [SHOW SETTINGS](/tidb-cloud-lake/sql/show-settings.md)。

另请参阅：[SET](/tidb-cloud-lake/sql/set.md)

## 语法 {#syntax}

```sql
-- Unset one setting
UNSET [ SESSION | GLOBAL ] <setting_name>

-- Unset multiple settings
UNSET [ SESSION | GLOBAL ] ( <setting_name>, <setting_name> ... )
```

| 参数 | 描述                                                                                                                                                                                         |
|-----------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SESSION   | 如果该设置具有全局级别的值，则移除会话级别的覆盖并恢复为全局设置。如果该设置只有会话级别的值，则恢复为默认设置。 |
| GLOBAL    | 移除全局级别的设置，并将其恢复为默认级别的值。                                                                                                                         |

| Lake-Query Version | 描述                                                                    |
|------------------------|--------------------------------------------------------------------------------|
| [-∞, v1.2.605)         | 默认情况下，`UNSET <setting_name>` 等同于 `UNSET GLOBAL <setting_name>`。  |
| [v1.2.605, +∞]         | 默认情况下，`UNSET <setting_name>` 等同于 `UNSET SESSION <setting_name>`。 |

└───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

-- Sets timezone to 'Asia/Shanghai' at global level
SET GLOBAL timezone = 'Asia/Shanghai';
SHOW SETTINGS LIKE 'timezone';

┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│   name   │     value     │ default │                                range                                │  level │     description    │  type  │
├──────────┼───────────────┼─────────┼─────────────────────────────────────────────────────────────────────┼────────┼────────────────────┼────────┤

└─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

-- Removes the global-level setting for timezone

SHOW SETTINGS LIKE 'timezone';
