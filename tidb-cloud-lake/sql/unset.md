# UNSET

1 つ以上のシステム設定をグローバルまたはデフォルトのレベルと値に戻します。設定レベルの詳細については、[Setting Levels](/tidb-cloud-lake/sql/show-settings.md#setting-levels) を参照してください。現在のすべての設定を表示するには、[SHOW SETTINGS](/tidb-cloud-lake/sql/show-settings.md) を使用します。

関連情報: [SET](/tidb-cloud-lake/sql/set.md)

## 構文 {#syntax}

```sql
-- Unset one setting
UNSET [ SESSION | GLOBAL ] <setting_name>

-- Unset multiple settings
UNSET [ SESSION | GLOBAL ] ( <setting_name>, <setting_name> ... )
```

| パラメータ | 説明                                                                                                                                                                                         |
|-----------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SESSION   | 設定にグローバルレベルの値がある場合、セッションレベルの上書きを削除してグローバル設定に戻します。設定がセッションレベルの値しか持たない場合は、デフォルト設定に戻します。 |
| GLOBAL    | グローバルレベルの設定を削除し、デフォルトレベルの値に戻します。                                                                                                                         |

| Lake-Query バージョン | 説明                                                                    |
|------------------------|--------------------------------------------------------------------------------|
| [-∞, v1.2.605)         | デフォルトでは、`UNSET <setting_name>` は `UNSET GLOBAL <setting_name>` と同じです。  |
| [v1.2.605, +∞]         | デフォルトでは、`UNSET <setting_name>` は `UNSET SESSION <setting_name>` と同じです。 |

└───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

-- Sets timezone to 'Asia/Shanghai' at global level
SET GLOBAL timezone = 'Asia/Shanghai';
SHOW SETTINGS LIKE 'timezone';

┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│   name   │     value     │ default │                                range                                │  level │     description    │  type  │
├──────────┼───────────────┼─────────┼─────────────────────────────────────────────────────────────────────┼────────┼────────────────────┼────────┤

-- Removes the global-level setting for timezone
UNSET GLOBAL timezone;
