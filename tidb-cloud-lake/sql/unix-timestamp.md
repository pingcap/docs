# TO_UNIX_TIMESTAMP

日付/時刻形式のタイムスタンプを Unix タイムスタンプ形式に変換します。Unix タイムスタンプは、1970 年 1 月 1 日 00:00:00 UTC からの経過秒数を表します。

## 構文 {#syntax}

```sql
TO_UNIX_TIMESTAMP(<expr>)
```

## 引数 {#arguments}

| 引数        | 説明                |
| ----------- | ------------------- |
| `<expr>`    | タイムスタンプ      |

timestamp データ型の詳細については、[Date & Time](/tidb-cloud-lake/sql/datetime.md) を参照してください。

## 戻り値の型 {#return-type}

`BIGINT`

## 例 {#examples}

```sql
SELECT
  to_unix_timestamp('2023-11-12 09:38:18.165575');

┌─────────────────────────────────────────────────┐
│ to_unix_timestamp('2023-11-12 09:38:18.165575') │
├─────────────────────────────────────────────────┤
│                                      1699781898 │
└─────────────────────────────────────────────────┘
```
