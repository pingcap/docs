# TO_UNIX_TIMESTAMP

将日期/时间格式的时间戳转换为 Unix 时间戳格式。Unix 时间戳表示自 1970 年 1 月 1 日 00:00:00 UTC 以来经过的秒数。

## 语法 {#syntax}

```sql
TO_UNIX_TIMESTAMP(<expr>)
```

## 参数 {#arguments}

| 参数 | 描述 |
| ----------- | ------------------- |
| `<expr>`    | 时间戳           |

有关时间戳数据类型的更多信息，请参见 [日期与时间](/tidb-cloud-lake/sql/datetime.md)。

## 返回类型 {#return-type}

`BIGINT`

## 示例 {#examples}

```sql
SELECT
  to_unix_timestamp('2023-11-12 09:38:18.165575');

┌─────────────────────────────────────────────────┐
│ to_unix_timestamp('2023-11-12 09:38:18.165575') │
├─────────────────────────────────────────────────┤
│                                      1699781898 │
└─────────────────────────────────────────────────┘
```
