# CURRENT_USER

サーバーが現在のクライアントを認証するために使用したアカウントの、ユーザー名とホスト名の組み合わせを返します。このアカウントによって、あなたのアクセス権限が決まります。戻り値は utf8 文字セットの文字列です。

## 構文 {#syntax}

```sql
CURRENT_USER()
```

## 例 {#examples}

```sql
SELECT CURRENT_USER();

┌────────────────┐
│ current_user() │
├────────────────┤
│ 'root'@'%'     │
└────────────────┘
```
