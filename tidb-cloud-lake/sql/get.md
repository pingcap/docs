# GET

`ARRAY` を含む `Variant` から `index` によって値を抽出するか、`OBJECT` を含む `Variant` から `field_name` によって値を抽出します。いずれかの引数が `NULL` の場合、値は `Variant` または `NULL` として返されます。

`GET` は `field_name` に対して大文字と小文字を区別して照合します。大文字と小文字を区別しない照合を行うには、`GET_IGNORE_CASE` を使用します。

## 構文 {#syntax}

```sql
GET( <variant>, <index> )

GET( <variant>, <field_name> )
```

## 引数 {#arguments}

| 引数 | 説明 |
|----------------|------------------------------------------------------------------|
| `<variant>`    | ARRAY または OBJECT のいずれかを含む VARIANT 値 |
| `<index>`      | ARRAY 内の値の位置を指定する Uint32 値 |
| `<field_name>` | OBJECT のキーと値のペアにおけるキーを指定する String 値 |

## 戻り値の型 {#return-type}

VARIANT

## 例 {#examples}

```sql
SELECT get(parse_json('[2.71, 3.14]'), 0);
+------------------------------------+
| get(parse_json('[2.71, 3.14]'), 0) |
+------------------------------------+
| 2.71                               |
+------------------------------------+

SELECT get(parse_json('{"aa":1, "aA":2, "Aa":3}'), 'aa');
+---------------------------------------------------+
| get(parse_json('{"aa":1, "aA":2, "Aa":3}'), 'aa') |
+---------------------------------------------------+
| 1                                                 |
+---------------------------------------------------+

SELECT get(parse_json('{"aa":1, "aA":2, "Aa":3}'), 'AA');
+---------------------------------------------------+
| get(parse_json('{"aa":1, "aA":2, "Aa":3}'), 'AA') |
+---------------------------------------------------+
| NULL                                              |
+---------------------------------------------------+
```
