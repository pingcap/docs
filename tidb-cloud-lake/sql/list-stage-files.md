# LIST STAGE FILES

stage 内のファイルを一覧表示します。

関連情報:

- [LIST_STAGE](/tidb-cloud-lake/sql/list-stage.md): この関数は stage 内のファイルを一覧表示し、拡張子に基づいて stage 内のファイルをフィルタリングしたり、各ファイルの詳細情報を取得したりできます。
- [PRESIGN](/tidb-cloud-lake/sql/presign.md): {{{ .lake }}} では、Presigned URL 方式を使用してファイルを stage にアップロードすることを推奨しています。
- [REMOVE STAGE FILES](/tidb-cloud-lake/sql/remove-stage-files.md): stage からファイルを削除します。

## 構文 {#syntax}

```sql
LIST { userStage | internalStage | externalStage } [ PATTERN = '<regex_pattern>' ]
```

`PATTERN` は、正規表現を使用して stage 済みファイルをフィルタリングします。これは `@<stage_name>[/<path>]` の後のファイルパス部分にマッチします。詳細は [PATTERN を使用した stage ファイルのフィルタリング](/tidb-cloud-lake/guides/stage-overview.md#filtering-staged-files-with-pattern) を参照してください。

## 例 {#examples}

以下の stage には、**books.parquet** という名前のファイルと、**2023** という名前のフォルダが含まれています。

LIST コマンドは、デフォルトですべてのファイルを stage 内から一覧表示します。

```sql
LIST @my_internal_stage;
+-----------------+------+------------------------------------+-------------------------------+---------+
|      name       | size |                md5                 |         last_modified         | creator |
+-----------------+------+------------------------------------+-------------------------------+---------+
| 2023/meta.log   |  475 | "4208ff530b252236e14b3cd797abdfbd" | 2023-04-19 20:23:24.000 +0000 | NULL    |
| 2023/query.log  | 1348 | "1c6654b207472c277fc8c6207c035e18" | 2023-04-19 20:23:24.000 +0000 | NULL    |
| 2023/readme.txt | 1193 | "8c0fbbebfedf26f93324541f97f5ac14" | 2023-04-19 20:23:24.000 +0000 | NULL    |
| books.parquet   |  998 | "88432bf90aadb79073682988b39d461c" | 2023-04-19 20:08:42.000 +0000 | NULL    |
+-----------------+------+------------------------------------+-------------------------------+---------+
```

**2023** フォルダ内のファイルを一覧表示するには、次のコマンドを実行します。

> **Note:**
>
> コマンド内のパスの末尾にはスラッシュ "/" を付ける必要があります。付けない場合、コマンドが期待どおりに動作せず、エラーになる可能性があります。

```sql
LIST @my_internal_stage/2023/;
+-----------------+------+------------------------------------+-------------------------------+---------+
|      name       | size |                md5                 |         last_modified         | creator |
+-----------------+------+------------------------------------+-------------------------------+---------+
| 2023/meta.log   |  475 | "4208ff530b252236e14b3cd797abdfbd" | 2023-04-19 20:23:24.000 +0000 | NULL    |
| 2023/query.log  | 1348 | "1c6654b207472c277fc8c6207c035e18" | 2023-04-19 20:23:24.000 +0000 | NULL    |
| 2023/readme.txt | 1193 | "8c0fbbebfedf26f93324541f97f5ac14" | 2023-04-19 20:23:24.000 +0000 | NULL    |
+-----------------+------+------------------------------------+-------------------------------+---------+
```

stage 内の `.log` 拡張子を持つすべてのファイルを一覧表示するには、次のコマンドを実行します。

```sql
LIST @my_internal_stage PATTERN = '.*[.]log';
+----------------+------+------------------------------------+-------------------------------+---------+
|      name      | size |                md5                 |         last_modified         | creator |
+----------------+------+------------------------------------+-------------------------------+---------+
| 2023/meta.log  |  475 | "4208ff530b252236e14b3cd797abdfbd" | 2023-04-19 20:23:24.000 +0000 | NULL    |
| 2023/query.log | 1348 | "1c6654b207472c277fc8c6207c035e18" | 2023-04-19 20:23:24.000 +0000 | NULL    |
+----------------+------+------------------------------------+-------------------------------+---------+
```
