# TO_MONDAY

日付または日時（timestamp/datetime）を直近の月曜日に切り下げます。日付を返します。

## 構文 {#syntax}

```sql
TO_MONDAY(<expr>)
```

## 引数 {#arguments}

| 引数 | 説明 |
| ----------- | ----------- |
| `<expr>` | 日付/タイムスタンプ |

## 戻り値の型 {#return-type}

`DATE`、`YYYY-MM-DD` 形式の日付を返します。

## 例 {#examples}

```sql
SELECT
    to_monday('2023-11-12 09:38:18.165575');

┌─────────────────────────────────────────┐
│ to_monday('2023-11-12 09:38:18.165575') │
├─────────────────────────────────────────┤
│ 2023-11-06                              │
└─────────────────────────────────────────┘
```
