# TO_MONDAY

将日期或带时间的日期（timestamp/datetime）向下舍入到最近的周一。返回日期。

## 语法 {#syntax}

```sql
TO_MONDAY(<expr>)
```

## 参数 {#arguments}

| 参数 | 描述 |
| ----------- | ----------- |
| `<expr>` | 日期/时间戳 |

## 返回类型 {#return-type}

`DATE`，以 “YYYY-MM-DD” 格式返回日期。

## 示例 {#examples}

```sql
SELECT
    to_monday('2023-11-12 09:38:18.165575');

┌─────────────────────────────────────────┐
│ to_monday('2023-11-12 09:38:18.165575') │
├─────────────────────────────────────────┤
│ 2023-11-06                              │
└─────────────────────────────────────────┘
```
