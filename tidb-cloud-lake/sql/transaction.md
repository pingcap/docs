# トランザクション

このページでは、{{{ .lake }}} におけるトランザクション操作の包括的な概要を、参照しやすいよう機能別に整理して提供します。

## トランザクション制御 {#transaction-control}

| コマンド | 説明 |
|---------|-------------|
| [BEGIN](/tidb-cloud-lake/sql/begin.md) | 新しいトランザクションを開始します |
| [COMMIT](/tidb-cloud-lake/sql/commit.md) | 現在のトランザクションをコミットし、すべての変更を永続化します |
| [ROLLBACK](/tidb-cloud-lake/sql/rollback.md) | 現在のトランザクションを中止し、すべての変更を破棄します |

## トランザクション情報 {#transaction-information}

| コマンド | 説明 |
|---------|-------------|
| [SHOW LOCKS](/tidb-cloud-lake/sql/show-locks.md) | システム内のアクティブなロックに関する情報を表示します |

> **Note:**
>
> {{{ .lake }}} のトランザクションは、SQL 操作を、完全に成功するか完全に失敗するかのいずれかであるアトミックな単位としてグループ化することで、データの一貫性を保証し、データベースの整合性を維持します。
