# MAP_CONTAINS_KEY

指定した MAP に指定したキーが含まれているかどうかを判定します。

## 構文 {#syntax}

```sql
MAP_CONTAINS_KEY( <map>, <key> )
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|-------------------------|
| `<map>`   | 検索対象の map です。 |
| `<key>`   | 検索するキーです。        |

## 戻り値の型 {#return-type}

Boolean。

## 例 {#examples}

```sql
SELECT MAP_CONTAINS_KEY({'a':1,'b':2,'c':3}, 'c');
┌────────────────────────────────────────────┐
│ map_contains_key({'a':1,'b':2,'c':3}, 'c') │
├────────────────────────────────────────────┤
│ true                                       │
└────────────────────────────────────────────┘

SELECT MAP_CONTAINS_KEY({'a':1,'b':2,'c':3}, 'x');
┌────────────────────────────────────────────┐
│ map_contains_key({'a':1,'b':2,'c':3}, 'x') │
├────────────────────────────────────────────┤
│ false                                      │
└────────────────────────────────────────────┘
```
