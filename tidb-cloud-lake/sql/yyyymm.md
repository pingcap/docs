# TO_YYYYMM

将日期或带时间的日期（timestamp/datetime）转换为包含年份和月份数字的 UInt32 数字。

## 语法 {#syntax}

```sql
TO_YYYYMM(<expr>)
```

## 参数 {#arguments}

| 参数 | 描述 |
|-----------|----------------|
| `<expr>`  | 日期/时间戳 |

## 返回类型 {#return-type}

`INT`，以 `YYYYMM` 格式返回。

## 示例 {#examples}

```sql
SELECT
  to_yyyymm('2023-11-12 09:38:18.165575');

┌─────────────────────────────────────────┐
│ to_yyyymm('2023-11-12 09:38:18.165575') │
│                  UInt32                 │
├─────────────────────────────────────────┤
│                                  202311 │
└─────────────────────────────────────────┘
```
