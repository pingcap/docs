# TO_YYYYMM

日付または日時（timestamp/datetime）を、年と月の番号を含む UInt32 の数値に変換します。

## 構文 {#syntax}

```sql
TO_YYYYMM(<expr>)
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|----------------|
| `<expr>`  | 日付/タイムスタンプ |

## 戻り値の型 {#return-type}

`INT`。`YYYYMM` 形式で返します。

## 例 {#examples}

```sql
SELECT
  to_yyyymm('2023-11-12 09:38:18.165575');

┌─────────────────────────────────────────┐
│ to_yyyymm('2023-11-12 09:38:18.165575') │
│                  UInt32                 │
├─────────────────────────────────────────┤
│                                  202311 │
└─────────────────────────────────────────┘
```
