# SQL Dialects & Conformance

このページでは、{{{ .lake }}} がサポートする SQL 方言の詳細と、SQL 標準への準拠状況、特に SQL:2011 の機能と {{{ .lake }}} におけるそのサポート状況について説明します。

## サポートされる SQL 方言 {#supported-sql-dialects}

SQL 方言とは、Structured Query Language の特定のバリエーションまたは種類を指します。{{{ .lake }}} はデフォルトで `PostgreSQL` 方言をサポートしており、他のサポート対象の方言へ柔軟に切り替えることもできます。サポートされる方言とその簡単な説明については、以下の表を参照してください。

| Dialect       | 概要                                                                                            | 詳細情報                     |
|---------------|-------------------------------------------------------------------------------------------------|------------------------------|
| `PostgreSQL`  | エンタープライズで一般的に使用される、デフォルトでサポートされる方言                           | <https://www.postgresql.org/>  |
| `MySQL`       | オープンソースのデータベース管理システム                                                        | <https://www.mysql.com/>       |
| `Hive`        | ビッグデータ処理向けのデータウェアハウス                                                        | <https://hive.apache.org/>     |
| `Prql`        | PRQL は、データ変換のためのモダンな言語であり、シンプルかつ強力なパイプライン型 SQL 代替言語です | <https://github.com/PRQL/prql> |
| `Experimental`| テストおよび研究向けの実験的な方言                                                              | N/A                          |

サポートされる SQL 方言を切り替える、または現在の方言を表示するには、`sql_dialect` 設定を使用します。

```sql title='Examples:'
-- Set SQL dialect to PRQL
SET sql_dialect = 'Prql';

-- Display current dialect
SHOW SETTINGS LIKE 'sql_dialect';
```
