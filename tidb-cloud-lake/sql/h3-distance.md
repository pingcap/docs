# H3_DISTANCE

指定された 2 つの [H3](https://eng.uber.com/h3/) インデックス間のグリッド距離を返します。

## 構文 {#syntax}

```sql
H3_DISTANCE(h3, a_h3)
```

## 例 {#examples}

```sql
SELECT H3_DISTANCE(599119489002373119, 599119491149856767);

┌─────────────────────────────────────────────────────┐
│ h3_distance(599119489002373119, 599119491149856767) │
├─────────────────────────────────────────────────────┤
│                                                   1 │
└─────────────────────────────────────────────────────┘
```
