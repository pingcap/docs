# COMMIT

トランザクション中に行われたすべての変更を保存します。トランザクションを開始し、その後保存または取り消すには、[BEGIN](/tidb-cloud-lake/sql/begin.md) と COMMIT/[ROLLBACK](/tidb-cloud-lake/sql/rollback.md) を組み合わせて使用する必要があります。

## 構文 {#syntax}

```sql
COMMIT
```
