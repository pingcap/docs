# COMMIT

保存事务期间所做的所有更改。[BEGIN](/tidb-cloud-lake/sql/begin.md) 和 COMMIT/[ROLLBACK](/tidb-cloud-lake/sql/rollback.md) 必须配合使用，以启动事务，并在之后保存或撤销该事务。

## 语法 {#syntax}

```sql
COMMIT
```
