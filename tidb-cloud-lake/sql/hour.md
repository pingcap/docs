# TO_HOUR

将带时间的日期（timestamp/datetime）转换为一个 UInt8 数值，表示 24 小时制中的小时数（0-23）。

该函数假定：如果时钟向前拨动，则拨快 1 小时并发生在凌晨 2 点；如果时钟向后拨动，则拨慢 1 小时并发生在凌晨 3 点。（这并不总是正确——即使在莫斯科，时钟也曾两次在不同时间调整。）

## 语法 {#syntax}

```sql
TO_HOUR(<expr>)
```

## 参数 {#arguments}

| 参数 | 描述 |
|-----------|-------------|
| `<expr>`  | 时间戳   |

## 返回类型 {#return-type}

`TINYINT`

## 示例 {#examples}

```sql
SELECT
    to_hour('2023-11-12 09:38:18.165575');

┌───────────────────────────────────────┐
│ to_hour('2023-11-12 09:38:18.165575') │
├───────────────────────────────────────┤
│                                     9 │
└───────────────────────────────────────┘
```
