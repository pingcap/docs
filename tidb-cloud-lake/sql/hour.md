# TO_HOUR

時刻を含む日付（timestamp/datetime）を、24時間表記の時（0～23）を表す UInt8 数値に変換します。

この関数は、時計が進められる場合は 1 時間進み午前 2 時に発生し、時計が戻される場合は 1 時間戻り午前 3 時に発生すると仮定します（これは常に正しいわけではなく、モスクワでさえ異なる時刻に 2 回変更されたことがあります）。

## 構文 {#syntax}

```sql
TO_HOUR(<expr>)
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|-------------|
| `<expr>`  | timestamp   |

## 戻り値の型 {#return-type}

`TINYINT`

## 例 {#examples}

```sql
SELECT
    to_hour('2023-11-12 09:38:18.165575');

┌───────────────────────────────────────┐
│ to_hour('2023-11-12 09:38:18.165575') │
├───────────────────────────────────────┤
│                                     9 │
└───────────────────────────────────────┘
```
