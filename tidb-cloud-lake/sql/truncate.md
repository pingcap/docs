# TRUNCATE

返回数字 `x` 截断到 `d` 位小数后的结果。如果 `d` 为 0，则结果不包含小数点或小数部分。`d` 可以为负数，这会使值 `x` 的小数点左侧的 `d` 位数字变为 0。`d` 的绝对值最大为 30；超过 30（或 -30）的位数会被截断。

## 语法 {#syntax}

```sql
TRUNCATE( <x, d> )
```

## 示例 {#examples}

```sql
SELECT TRUNCATE(1.223, 1);

┌────────────────────┐
│ truncate(1.223, 1) │
├────────────────────┤
│ 1.2                │
└────────────────────┘
```
