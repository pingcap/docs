# TRUNCATE

数値 `x` を小数点以下 `d` 桁で切り捨てて返します。`d` が 0 の場合、結果には小数点および小数部分は含まれません。`d` には負の値を指定でき、その場合は値 `x` の小数点の左側にある `d` 桁が 0 になります。`d` の絶対値の最大値は 30 で、30（または -30）を超える桁は切り捨てられます。

## 構文 {#syntax}

```sql
TRUNCATE( <x, d> )
```

## 例 {#examples}

```sql
SELECT TRUNCATE(1.223, 1);

┌────────────────────┐
│ truncate(1.223, 1) │
├────────────────────┤
│ 1.2                │
└────────────────────┘
```
