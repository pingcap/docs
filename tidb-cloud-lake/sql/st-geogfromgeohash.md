# ST_GEOGFROMGEOHASH

返回一个 GEOGRAPHY 对象，用于表示 [geohash](https://en.wikipedia.org/wiki/Geohash) 边界所对应的多边形。

## 语法 {#syntax}

```sql
ST_GEOGFROMGEOHASH(<geohash>)
```

## 参数 {#arguments}

| 参数        | 描述                        |
|-------------|-----------------------------|
| `<geohash>` | 该参数必须是一个 geohash。 |

## 返回类型 {#return-type}

Geography。

## 示例 {#examples}

```sql
SELECT
  ST_ASWKT(
    ST_GEOGFROMGEOHASH(
      '9q60y60rhs'
    )
  ) AS pipeline_geography;
```
