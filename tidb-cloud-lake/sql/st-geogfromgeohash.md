# ST_GEOGFROMGEOHASH

[geohash](https://en.wikipedia.org/wiki/Geohash) の境界を表すポリゴンに対応する GEOGRAPHY オブジェクトを返します。

## 構文 {#syntax}

```sql
ST_GEOGFROMGEOHASH(<geohash>)
```

## 引数 {#arguments}

| 引数 | 説明 |
|-------------|---------------------------------|
| `<geohash>` | 引数は geohash である必要があります。 |

## 戻り値の型 {#return-type}

Geography。

## 例 {#examples}

```sql
SELECT
  ST_ASWKT(
    ST_GEOGFROMGEOHASH(
      '9q60y60rhs'
    )
  ) AS pipeline_geography;
```
