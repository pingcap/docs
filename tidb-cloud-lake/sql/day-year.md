# TO_DAY_OF_YEAR

日付または時刻付きの日付（timestamp/datetime）を、その年の通算日（1-366）を表す UInt16 の数値に変換します。

## 構文 {#syntax}

```sql
TO_DAY_OF_YEAR(<expr>)
```

## 引数 {#arguments}

| 引数 | 説明 |
| ----------- | ----------- |
| `<expr>` | 日付/タイムスタンプ |

## 戻り値の型 {#return-type}

`SMALLINT`

## 例 {#examples}

```sql
SELECT
    to_day_of_year('2023-11-12 09:38:18.165575');

┌──────────────────────────────────────────────┐
│ to_day_of_year('2023-11-12 09:38:18.165575') │
├──────────────────────────────────────────────┤
│                                          316 │
└──────────────────────────────────────────────┘
```
