# H3_TO_PARENT

解像度 `parent_res` において `h3` を含む親インデックスを返します。0 が返される場合は、エラーが発生したことを意味します。

## 構文 {#syntax}

```sql
H3_TO_PARENT(h3, parent_res)
```

## 例 {#examples}

```sql
SELECT H3_TO_PARENT(635318325446452991, 12);

┌──────────────────────────────────────┐
│ h3_to_parent(635318325446452991, 12) │
├──────────────────────────────────────┤
│                   630814725819082751 │
└──────────────────────────────────────┘
```
