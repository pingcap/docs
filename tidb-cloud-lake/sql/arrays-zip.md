# ARRAYS_ZIP

複数の配列を 1 つの配列タプルにマージします。

## 構文 {#syntax}

```sql
ARRAYS_ZIP( <array1> [, ...] )
```

## 引数 {#arguments}

| 引数 | 説明 |
|------------|-------------------|
| `<arrayN>` | 入力 ARRAY です。 |

> **Note:**
>
> - 各配列の長さは同じである必要があります。

## 戻り値の型 {#return-type}

Array(Tuple)。

## 例 {#examples}

```sql
SELECT ARRAYS_ZIP([1, 2, 3], ['a', 'b', 'c']);
┌────────────────────────────────────────┐
│ arrays_zip([1, 2, 3], ['a', 'b', 'c']) │
├────────────────────────────────────────┤
│ [(1,'a'),(2,'b'),(3,'c')]              │
└────────────────────────────────────────┘
```
