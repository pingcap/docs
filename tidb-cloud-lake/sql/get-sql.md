# GET

配列からインデックス（1始まり）で要素を返します。

## 構文 {#syntax}

```sql
GET( <array>, <index> )
```

## エイリアス {#aliases}

- [ARRAY_GET](/tidb-cloud-lake/sql/array-get.md)

## 例 {#examples}

```sql
SELECT GET([1, 2], 2), ARRAY_GET([1, 2], 2);

┌───────────────────────────────────────┐
│ get([1, 2], 2) │ array_get([1, 2], 2) │
├────────────────┼──────────────────────┤
│              2 │                    2 │
└───────────────────────────────────────┘
```
