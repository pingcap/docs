# SUB_BITMAP

从起始索引开始，按指定大小生成源位图的子位图。

## 语法 {#syntax}

```sql
SUB_BITMAP( <bitmap>, <start>, <size> )
```

## 示例 {#examples}

```sql
SELECT SUB_BITMAP(BUILD_BITMAP([1, 2, 3, 4, 5]), 1, 3)::String;

┌─────────────────────────────────────────────────────────┐
│ sub_bitmap(build_bitmap([1, 2, 3, 4, 5]), 1, 3)::string │
├─────────────────────────────────────────────────────────┤
│ 2,3,4                                                   │
└─────────────────────────────────────────────────────────┘
```
