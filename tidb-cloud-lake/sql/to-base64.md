# TO_BASE64

文字列引数を base-64 エンコード形式に変換し、その結果を文字列として返します。引数が文字列でない場合は、変換の前に文字列に変換されます。引数が NULL の場合、結果は NULL になります。

## 構文 {#syntax}

```sql
TO_BASE64(<v>)
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|-------------|
| `<v>`     | 値。  |

## 戻り値の型 {#return-type}

`VARCHAR`

## 例 {#examples}

```sql
SELECT TO_BASE64('abc');
+------------------+
| TO_BASE64('abc') |
+------------------+
| YWJj             |
+------------------+
```
