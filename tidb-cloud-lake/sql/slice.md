# SLICE

按索引（从 1 开始）从数组中提取一个切片。

## 语法 {#syntax}

```sql
SLICE( <array>, <start>[, <end>] )
```

## 别名 {#aliases}

- [ARRAY_SLICE](/tidb-cloud-lake/sql/array-slice.md)

## 示例 {#examples}

```sql
SELECT ARRAY_SLICE([1, 21, 32, 4], 2, 3), SLICE([1, 21, 32, 4], 2, 3);

┌─────────────────────────────────────────────────────────────────┐
│ array_slice([1, 21, 32, 4], 2, 3) │ slice([1, 21, 32, 4], 2, 3) │
├───────────────────────────────────┼─────────────────────────────┤
│ [21,32]                           │ [21,32]                     │
└─────────────────────────────────────────────────────────────────┘
```
