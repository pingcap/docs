# CHECK_JSON

检查 JSON 文档的有效性。如果输入字符串是有效的 JSON 文档或 `NULL`，则输出为 `NULL`。如果输入无法转换为有效的 JSON 值，则输出字符串包含错误信息。

## 语法 {#syntax}

```sql
CHECK_JSON( <expr> )
```

## 参数 {#arguments}

| 参数 | 描述 |
|-----------|------------------------------|
| `<expr>`  | 一个字符串类型的表达式 |

## 返回类型 {#return-type}

字符串

## 示例 {#examples}

```sql
SELECT check_json('[1,2,3]');
+-----------------------+
| check_json('[1,2,3]') |
+-----------------------+
| NULL                  |
+-----------------------+

SELECT check_json('{"key":"val"}');
+-----------------------------+
| check_json('{"key":"val"}') |
+-----------------------------+
| NULL                        |
+-----------------------------+

SELECT check_json('{"key":');
+----------------------------------------------+
| check_json('{"key":')                        |
+----------------------------------------------+
| EOF while parsing a value at line 1 column 7 |
+----------------------------------------------+
```
