# CHECK_JSON

JSON ドキュメントの妥当性をチェックします。入力文字列が有効な JSON ドキュメントまたは `NULL` の場合、出力は `NULL` です。入力を有効な JSON 値に変換できない場合、出力文字列にはエラーメッセージが含まれます。

## 構文 {#syntax}

```sql
CHECK_JSON( <expr> )
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|------------------------------|
| `<expr>`  | 文字列型の式 |

## 戻り値の型 {#return-type}

文字列

## 例 {#examples}

```sql
SELECT check_json('[1,2,3]');
+-----------------------+
| check_json('[1,2,3]') |
+-----------------------+
| NULL                  |
+-----------------------+

SELECT check_json('{"key":"val"}');
+-----------------------------+
| check_json('{"key":"val"}') |
+-----------------------------+
| NULL                        |
+-----------------------------+

SELECT check_json('{"key":');
+----------------------------------------------+
| check_json('{"key":')                        |
+----------------------------------------------+
| EOF while parsing a value at line 1 column 7 |
+----------------------------------------------+
```
