# 算術演算子

| 演算子                | 説明                                                      | 例                         | 結果      |
| --------------------- | --------------------------------------------------------- | -------------------------- | --------- |
| **+ (unary)**         | `a` を返します                                            | **+5**                     | 5         |
| **+**                 | 2 つの数値式を加算します                                  | **4 + 1**                  | 5         |
| **- (unary)**         | 数値式を負の値にします                                    | **-5**                     | -5        |
| **-**                 | 2 つの数値式を減算します                                  | **4 - 1**                  | 3         |
| **\***                | 2 つの数値式を乗算します                                  | **4 \* 1**                 | 4         |
| **/**                 | ある数値式 (`a`) を別の数値式 (`b`) で除算します          | **4 / 2**                  | 2         |
| **//**                | 数値式の整数除算を計算します                              | **4 // 3**                 | 1         |
| **%**                 | 数値式の剰余を計算します                                  | **4 % 2**                  | 0         |
| **^**                 | 数値式のべき乗を計算します                                | **4 ^ 2**                  | 16        |
| **&verbar;/**         | 数値式の平方根を計算します                                | **&verbar;/ 25.0**         | 5         |
| **&verbar;&verbar;/** | 数値式の立方根を計算します                                | **&verbar;&verbar;/ 27.0** | 3         |
| **@**                 | 数値式の絶対値を計算します                                | **@ -5.0**                 | 5         |
| **&**                 | 数値式のビット単位 AND を計算します                       | **91 & 15**                | 11        |
| **&verbar;**          | 数値式のビット単位 OR を計算します                        | **32 &verbar; 3**          | 35        |
| **#**                 | 数値式のビット単位 XOR を計算します                       | **17 # 5**                 | 20        |
| **~**                 | 数値式のビット単位 NOT を計算します                       | **~ 1**                    | ~2        |
| **`<<`**              | 数値式のビット左シフトを計算します                        | **1 `<<` 4**               | 16        |
| **>>**                | 数値式のビット右シフトを計算します                        | **8 >> 2**                 | 2         |
| **`<->`**             | ベクトル間のユークリッド距離（L2 ノルム）を計算します     | **[1, 2] `<->` [2, 3]**    | 1.4142135 |
