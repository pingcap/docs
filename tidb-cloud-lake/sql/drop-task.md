# DROP TASK

DROP TASK ステートメントは、既存のタスクを削除するために使用されます。

**NOTICE:** この機能は、{{{ .lake }}} でのみ追加設定なしですぐに利用できます。

## 構文 {#syntax}

```sql
DROP TASK [ IF EXISTS ] <name>
```

| パラメータ                        | 説明                                                                                        |
|----------------------------------|------------------------------------------------------------------------------------------------------|
| IF EXISTS                        | 任意。指定した場合、同じ名前のタスクがすでに存在するときにのみ、そのタスクが削除されます。 |
| name                             | タスクの名前です。これは必須フィールドです。                                                       |

## 使用上の注意 {#usage-notes}

- DAG 内の先行タスクが削除されると、このタスクを先行タスクとして指定していた以前のすべての子タスクは、他のタスクがそれらの以前の子タスクを先行タスクとして指定しているかどうかに応じて、スタンドアロンタスクまたはルートタスクになります。これらの以前の子タスクはデフォルトで一時停止状態になるため、手動で再開する必要があります。
- DROP の前に Root Task を一時停止する必要があります

## 使用例 {#usage-examples}

```sql
DROP TASK IF EXISTS mytask;
```

このコマンドは、`mytask` という名前のタスクが存在する場合に削除します。
