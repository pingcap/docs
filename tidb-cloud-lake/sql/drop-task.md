# DROP TASK

`DROP TASK` 语句用于删除现有任务。

**注意：** 此功能默认仅在 {{{ .lake }}} 中开箱即用。

## 语法 {#syntax}

```sql
DROP TASK [ IF EXISTS ] <name>
```

| 参数                             | 描述                                                                                         |
|----------------------------------|----------------------------------------------------------------------------------------------|
| IF EXISTS                        | 可选。如果指定了该参数，则仅当已存在同名任务时才会删除该任务。 |
| name                             | 任务名称。这是必填字段。                                                       |

## 使用说明 {#usage-notes}

- 如果删除了 DAG 中的前驱任务，则所有将该任务标识为前驱任务的原子任务会变为独立任务或根任务，具体取决于是否还有其他任务将这些原子任务标识为其前驱任务。这些原子任务默认会被挂起，必须手动恢复。
- 在执行 DROP 之前，必须先挂起 Root Task。

## 使用示例 {#usage-examples}

```sql
DROP TASK IF EXISTS mytask;
```

如果任务 `mytask` 存在，此命令会将其删除。
