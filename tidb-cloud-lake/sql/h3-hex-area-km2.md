# H3_HEX_AREA_KM2

返回给定分辨率下六边形的平均面积（单位：平方千米）。不包括五边形。

## 语法 {#syntax}

```sql
H3_HEX_AREA_KM2(res)
```

## 示例 {#examples}

```sql
SELECT H3_HEX_AREA_KM2(1);

┌────────────────────┐
│ h3_hex_area_km2(1) │
├────────────────────┤
│  609788.4417941332 │
└────────────────────┘
```
