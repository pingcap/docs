# H3_HEX_AREA_KM2

指定した解像度における六角形の平均面積を平方キロメートル単位で返します。五角形は含まれません。

## 構文 {#syntax}

```sql
H3_HEX_AREA_KM2(res)
```

## 例 {#examples}

```sql
SELECT H3_HEX_AREA_KM2(1);

┌────────────────────┐
│ h3_hex_area_km2(1) │
├────────────────────┤
│  609788.4417941332 │
└────────────────────┘
```
