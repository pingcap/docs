# USE WAREHOUSE

将当前会话绑定到特定的计算集群 (Warehouse)。该会话中的后续查询将使用此计算集群执行。

## 语法 {#syntax}

```sql
USE WAREHOUSE <warehouse_name>
```

| 参数 | 描述 |
| -------------- | ---------------------------------------------------------------------------------------------------- |
| warehouse_name | 要使用的计算集群名称。该命令会验证该计算集群是否存在且可访问。 |

## 示例 {#examples}

将某个计算集群设置为当前会话的活动计算集群：

```sql
USE WAREHOUSE 'my-warehouse';
```
