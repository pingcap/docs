# TIME_SLOT

時刻を30分単位に丸めます。

## 構文 {#syntax}

```sql
time_slot(<expr>)
```

## 引数 {#arguments}

| 引数 | 説明 |
| ----------- | ----------- |
| `<expr>`    | timestamp   |

## 戻り値の型 {#return-type}

`TIMESTAMP`。`YYYY-MM-DD hh:mm:ss.ffffff` 形式で返します。

## 例 {#examples}

```sql
SELECT
  time_slot('2023-11-12 09:38:18.165575');

┌─────────────────────────────────────────┐
│ time_slot('2023-11-12 09:38:18.165575') │
├─────────────────────────────────────────┤
│ 2023-11-12 09:30:00                     │
└─────────────────────────────────────────┘
```
