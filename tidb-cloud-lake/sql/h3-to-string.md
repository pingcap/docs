# H3_TO_STRING

指定された [H3](https://eng.uber.com/h3/) インデックスの表現を文字列表現に変換します。

## 構文 {#syntax}

```sql
H3_TO_STRING(h3)
```

## 例 {#examples}

```sql
SELECT H3_TO_STRING(635318325446452991);

┌──────────────────────────────────┐
│ h3_to_string(635318325446452991) │
├──────────────────────────────────┤
│ 8d11aa6a38826ff                  │
└──────────────────────────────────┘
```
