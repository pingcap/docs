# MAP_INSERT

新しいキーと値のペアを挿入した入力 MAP からなる新しい MAP を返します（既存のキーは新しい値で更新されます）。

## 構文 {#syntax}

```sql
MAP_INSERT( <map>, <key>, <value> [, <updateFlag> ] )
```

## 引数 {#arguments}

| 引数 | 説明 |
|----------------|----------------------------------------------------------------------------------------------|
| `<map>`        | 入力 MAP。                                                                               |
| `<key>`        | MAP に挿入する新しいキー。                                                          |
| `<value>`      | MAP に挿入する新しい値。                                                        |
| `<updateFlag>` | 既存のキーを上書きできるかどうかを示す boolean フラグです。デフォルトは FALSE です。 |

## 戻り値の型 {#return-type}

Map。

## 例 {#examples}

```sql
SELECT MAP_INSERT({'a':1,'b':2,'c':3}, 'd', 4);
┌─────────────────────────────────────────┐
│ map_insert({'a':1,'b':2,'c':3}, 'd', 4) │
├─────────────────────────────────────────┤
│ {'a':1,'b':2,'c':3,'d':4}               │
└─────────────────────────────────────────┘

SELECT MAP_INSERT({'a':1,'b':2,'c':3}, 'a', 5, true);
┌───────────────────────────────────────────────┐
│ map_insert({'a':1,'b':2,'c':3}, 'a', 5, TRUE) │
├───────────────────────────────────────────────┤
│ {'a':5,'b':2,'c':3}                           │
└───────────────────────────────────────────────┘
```
