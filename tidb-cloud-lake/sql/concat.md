# CONCAT

引数を連結した結果の文字列を返します。引数は 1 つ以上指定できます。すべての引数が非バイナリ文字列の場合、結果は非バイナリ文字列になります。引数にバイナリ文字列が含まれる場合、結果はバイナリ文字列になります。数値引数は、対応する非バイナリ文字列形式に変換されます。

## 構文 {#syntax}

```sql
CONCAT(<expr1>, ...)
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|-------------|
| `<expr1>` | 文字列      |

## 戻り値の型 {#return-type}

`VARCHAR` データ型の値、または `NULL` データ型です。

## 例 {#examples}

```sql
SELECT CONCAT('data', 'lake');
+------------------------+
| concat('data', 'lake') |
+------------------------+
| datalake               |
+------------------------+

SELECT CONCAT('data', NULL, 'lake');
+------------------------------+
| CONCAT('data', NULL, 'lake') |
+------------------------------+
|                         NULL |
+------------------------------+

SELECT CONCAT('14.3');
+----------------+
| concat('14.3') |
+----------------+
| 14.3           |
+----------------+
```
