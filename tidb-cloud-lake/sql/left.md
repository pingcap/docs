# LEFT

文字列 `str` の左端から `len` 文字を返します。いずれかの引数が NULL の場合は NULL を返します。`len` が `str` の長さより大きい場合は、`str` 全体を返します。

## 構文 {#syntax}

```sql
LEFT(<str>, <len>);
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|----------------------------------------------------------|
| `<str>`   | 文字を抽出する元の文字列 |
| `<len>`   | 文字数 |

## 戻り値の型 {#return-type}

`VARCHAR`

## 例 {#examples}

```sql
SELECT LEFT('foobarbar', 5), LEFT('foobarbar', 10);

┌──────────────────────────────────────────────┐
│ left('foobarbar', 5) │ left('foobarbar', 10) │
├──────────────────────┼───────────────────────┤
│ fooba                │ foobarbar             │
└──────────────────────────────────────────────┘
```
