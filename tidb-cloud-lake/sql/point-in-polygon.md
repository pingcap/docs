# POINT_IN_POLYGON

複数の点を結んで形成される多角形の内側に、指定した点が含まれるかどうかを計算します。多角形は、座標の組を出現順に結んでできる閉じた図形です。座標の組の順序を変更すると、異なる図形になる場合があります。

## 構文 {#syntax}

```sql
POINT_IN_POLYGON((x,y), [(a,b), (c,d), (e,f) ... ])
```

## 例 {#examples}

```sql
SELECT POINT_IN_POLYGON((3., 3.), [(6, 0), (8, 4), (5, 8), (0, 2)]);

┌────────────────────────────────────────────────────────────┐
│ point_in_polygon((3, 3), [(6, 0), (8, 4), (5, 8), (0, 2)]) │
├────────────────────────────────────────────────────────────┤
│                                                          1 │
└────────────────────────────────────────────────────────────┘
```
