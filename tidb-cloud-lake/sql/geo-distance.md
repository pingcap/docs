# GEO_DISTANCE

返回地球上两点之间以米为单位的近似距离。点的位置使用经度和纬度（单位为度）指定，距离基于 WGS84 的近似方法计算。

## 语法 {#syntax}

```sql
GEO_DISTANCE(<lon1>, <lat1>, <lon2>, <lat2>)
```

## 参数 {#arguments}

| 参数 | 描述 |
|-----------|-------------|
| `<lon1>` | 第一个点的经度，单位为度。 |
| `<lat1>` | 第一个点的纬度，单位为度。 |
| `<lon2>` | 第二个点的经度，单位为度。 |
| `<lat2>` | 第二个点的纬度，单位为度。 |

## 返回类型 {#return-type}

Float32。

## 示例 {#examples}

```sql
SELECT GEO_DISTANCE(55.755831, 37.617673, -55.755831, -37.617673) AS distance;

╭────────────╮
│  distance  │
├────────────┤
│ 14128353.0 │
╰────────────╯
```
