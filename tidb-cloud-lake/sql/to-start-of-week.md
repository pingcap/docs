# TO_START_OF_WEEK

日付または日時（timestamp/datetime）に対して、その週の最初の日を返します。週の最初の日は、引数 `mode` で Sunday または Monday のいずれかを指定できます。

## 構文 {#syntax}

```sql
TO_START_OF_WEEK(<expr> [, mode])
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|-----------------------------------------------------------------------------------------------------|
| `<expr>`  | date/timestamp |
| `[mode]`  | 任意。0 の場合、結果は日曜日になります。それ以外の場合、結果は月曜日になります。デフォルト値は 0 です。 |

## 戻り値の型 {#return-type}

`DATE`。日付を `YYYY-MM-DD` 形式で返します。

## 例 {#examples}

```sql
SELECT
  to_start_of_week('2023-11-12 09:38:18.165575');

┌────────────────────────────────────────────────┐
│ to_start_of_week('2023-11-12 09:38:18.165575') │
├────────────────────────────────────────────────┤
│ 2023-11-12                                     │
└────────────────────────────────────────────────┘
```
