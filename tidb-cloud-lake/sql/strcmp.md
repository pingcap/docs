# STRCMP

文字列が同じ場合は 0 を返し、第 1 引数が第 2 引数より小さい場合は -1、それ以外の場合は 1 を返します。

## 構文 {#syntax}

```sql
STRCMP(<expr1> ,<expr2>)
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|-------------|
| `<expr1>` | 文字列です。 |
| `<expr2>` | 文字列です。 |

## 戻り値の型 {#return-type}

`BIGINT`

## 例 {#examples}

```sql
SELECT STRCMP('text', 'text2');
+-------------------------+
| STRCMP('text', 'text2') |
+-------------------------+
|                      -1 |
+-------------------------+

SELECT STRCMP('text2', 'text');
+-------------------------+
| STRCMP('text2', 'text') |
+-------------------------+
|                       1 |
+-------------------------+

SELECT STRCMP('text', 'text');
+------------------------+
| STRCMP('text', 'text') |
+------------------------+
|                      0 |
+------------------------+
```
