# SIGN

`x` が負、ゼロ、または正のいずれであるかに応じて、引数の符号を -1、0、または 1 として返します。引数が NULL の場合は NULL を返します。

## 構文 {#syntax}

```sql
SIGN( <x> )
```

## 例 {#examples}

```sql
SELECT SIGN(0);

┌─────────┐
│ sign(0) │
├─────────┤
│       0 │
└─────────┘
```
