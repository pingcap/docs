# MAP_SIZE

MAP のサイズを返します。

## 構文 {#syntax}

```sql
MAP_SIZE( <map> )
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|----------------|
| `<map>`   | 入力 MAP。 |

## 戻り値の型 {#return-type}

UInt64。

## 例 {#examples}

```sql
SELECT MAP_SIZE({'a':1,'b':2,'c':3});

┌───────────────────────────────┐
│ map_size({'a':1,'b':2,'c':3}) │
├───────────────────────────────┤
│ 3                             │
└───────────────────────────────┘
```
