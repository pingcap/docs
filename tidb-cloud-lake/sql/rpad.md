# RPAD

文字列 str を、文字列 padstr を使って右側に埋め込み、長さ len 文字にして返します。str が len より長い場合、返り値は len 文字に切り詰められます。

## 構文 {#syntax}

```sql
RPAD(<str>, <len>, <padstr>)
```

## 引数 {#arguments}

| 引数 | 説明 |
|------------|-----------------|
| `<str>`    | 文字列です。 |
| `<len>`    | 長さです。 |
| `<padstr>` | 埋め込みに使用する文字列です。 |

## 戻り値の型 {#return-type}

`VARCHAR`

## 例 {#examples}

```sql
SELECT RPAD('hi',5,'?');
+--------------------+
| RPAD('hi', 5, '?') |
+--------------------+
| hi???              |
+--------------------+

SELECT RPAD('hi',1,'?');
+--------------------+
| RPAD('hi', 1, '?') |
+--------------------+
| h                  |
+--------------------+
```
