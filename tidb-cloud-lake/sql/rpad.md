# RPAD

返回字符串 str，在其右侧使用字符串 padstr 填充，直到长度达到 len 个字符。如果 str 的长度大于 len，则返回值会被截短为 len 个字符。

## 语法 {#syntax}

```sql
RPAD(<str>, <len>, <padstr>)
```

## 参数 {#arguments}

| 参数       | 描述         |
|------------|--------------|
| `<str>`    | 字符串。     |
| `<len>`    | 长度。       |
| `<padstr>` | 填充字符串。 |

## 返回类型 {#return-type}

`VARCHAR`

## 示例 {#examples}

```sql
SELECT RPAD('hi',5,'?');
+--------------------+
| RPAD('hi', 5, '?') |
+--------------------+
| hi???              |
+--------------------+

SELECT RPAD('hi',1,'?');
+--------------------+
| RPAD('hi', 1, '?') |
+--------------------+
| h                  |
+--------------------+
```
