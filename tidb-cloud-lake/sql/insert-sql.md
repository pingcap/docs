# INSERT

文字列 str のうち、位置 pos から始まる長さ len の部分文字列を文字列 newstr で置き換えた結果を返します。pos が文字列の長さの範囲内にない場合は、元の文字列を返します。len が残りの文字列の長さの範囲内にない場合は、位置 pos から文字列の残りを置き換えます。いずれかの引数が NULL の場合は NULL を返します。

## 構文 {#syntax}

```sql
INSERT(<str>, <pos>, <len>, <newstr>)
```

## 引数 {#arguments}

| 引数 | 説明 |
|------------|-----------------|
| `<str>`    | 文字列です。     |
| `<pos>`    | 位置です。   |
| `<len>`    | 長さです。     |
| `<newstr>` | 新しい文字列です。 |

## 戻り値の型 {#return-type}

`VARCHAR`
