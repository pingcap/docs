# VECTOR_NORM

ベクトルの長さまたは大きさを表す、ベクトルの L2 ノルム（ユークリッドノルム）を計算します。

## 構文 {#syntax}

```sql
VECTOR_NORM(vector)
```

## 引数 {#arguments}

- `vector`: 入力ベクトル（VECTOR データ型）

## 戻り値 {#returns}

ベクトルの L2 ノルム（大きさ）を表す FLOAT 値を返します。

## 説明 {#description}

`VECTOR_NORM` 関数は、ベクトルの L2 ノルム（ユークリッドノルムとも呼ばれます）を計算します。これは、ユークリッド空間におけるベクトルの長さまたは大きさを表します。この関数は次の処理を行います。

1. ベクトルの各要素を二乗する
2. 二乗したすべての値を合計する
3. 合計値の平方根を返す

実装されている数式は次のとおりです。

```
vector_norm(v) = √(Σ(vᵢ²))
```

ここで、vᵢ は入力ベクトルの要素です。

ベクトルノルムは、次のような場面で基本となる概念です。

- ベクトルを単位長に正規化する
- 機械学習でベクトルの大きさを測定する
- 距離や類似度を計算する
- 特徴量のスケーリングと前処理
- 大きさを扱う物理計算

> **Note:**
>
> この関数は {{{ .lake }}} 内でベクトル計算を実行し、外部 API には依存しません。

## 例 {#examples}

```sql
-- Calculate vector magnitude (length)
SELECT
    VECTOR_NORM([3,4]::VECTOR(2)) AS norm_2d,
    VECTOR_NORM([1,2,3]::VECTOR(3)) AS norm_3d,
    VECTOR_NORM([0,0,0]::VECTOR(3)) AS zero_vector;
```

結果:

```
┌─────────┬───────────┬─────────────┐
│ norm_2d │  norm_3d  │ zero_vector │
├─────────┼───────────┼─────────────┤
│     5.0 │ 3.7416575 │         0.0 │
└─────────┴───────────┴─────────────┘
```
