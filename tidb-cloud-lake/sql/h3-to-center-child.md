# H3_TO_CENTER_CHILD

指定した解像度における中心の子インデックスを返します。

## 構文 {#syntax}

```sql
H3_TO_CENTER_CHILD(h3, res)
```

## 例 {#examples}

```sql
SELECT H3_TO_CENTER_CHILD(599119489002373119, 15);

┌────────────────────────────────────────────┐
│ h3_to_center_child(599119489002373119, 15) │
├────────────────────────────────────────────┤
│                         644155484202336256 │
└────────────────────────────────────────────┘
```
