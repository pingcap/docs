# Explain Commands

このページでは、{{{ .lake }}} の explain 関連コマンドのリファレンス情報を提供します。

## コマンド概要 {#commands-overview}

| Command | ユースケース |
|---------|----------|
| [`EXPLAIN`](/tidb-cloud-lake/sql/explain.md) | クエリ構造と最適化の理解 |
| [`EXPLAIN ANALYZE`](/tidb-cloud-lake/sql/explain-analyze.md) | 実行時統計を使用したパフォーマンス分析 |
| [`EXPLAIN ANALYZE GRAPHICAL`](/tidb-cloud-lake/sql/explain-analyze-graphical.md) | 視覚的なパフォーマンス分析（LakeSQL のみ） |
| [`EXPLAIN AST`](/tidb-cloud-lake/sql/explain-ast.md) | SQL の解析と構文分析 |
| [`EXPLAIN PERF`](/tidb-cloud-lake/sql/explain-perf.md) | クエリパフォーマンスのプロファイリング（LakeSQL のみ） |
| [`EXPLAIN RAW`](/tidb-cloud-lake/sql/explain-raw.md) | 内部クエリ処理の分析 |
| [`EXPLAIN SYNTAX`](/tidb-cloud-lake/sql/explain-syntax.md) | SQL コードの整形と標準化 |
