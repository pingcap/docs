# TO_DAY_OF_WEEK

将日期或带时间的日期（timestamp/datetime）转换为一个 UInt8 数字，表示一周中的第几天（星期一为 1，星期日为 7）。

## 语法 {#syntax}

```sql
TO_DAY_OF_WEEK(<expr>)
```

## 参数 {#arguments}

| 参数 | 描述 |
|-----------|----------------|
| `<expr>`  | 日期/时间戳 |

## 返回类型 {#return-type}

`TINYINT`

## 示例 {#examples}

```sql

SELECT
    to_day_of_week('2023-11-12 09:38:18.165575');

┌──────────────────────────────────────────────┐
│ to_day_of_week('2023-11-12 09:38:18.165575') │
├──────────────────────────────────────────────┤
│                                            7 │
└──────────────────────────────────────────────┘
```
