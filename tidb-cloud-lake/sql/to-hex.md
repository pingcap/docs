# TO_HEX

文字列引数 str に対して、TO_HEX() は str の16進文字列表現を返します。このとき、str 内の各文字の各バイトは2桁の16進数に変換されます。この操作の逆は UNHEX() 関数によって実行されます。

数値引数 N に対して、TO_HEX() は N の値を longlong (BIGINT) 数値として扱った16進文字列表現を返します。

## 構文 {#syntax}

```sql
TO_HEX(<expr>)
```

## エイリアス {#aliases}

- [HEX](/tidb-cloud-lake/sql/hex.md)

## 例 {#examples}

```sql
SELECT HEX('abc'), TO_HEX('abc');

┌────────────────────────────┐
│ hex('abc') │ to_hex('abc') │
├────────────┼───────────────┤
│ 616263     │ 616263        │
└────────────────────────────┘

SELECT HEX(255), TO_HEX(255);

┌────────────────────────┐
│ hex(255) │ to_hex(255) │
├──────────┼─────────────┤
│ ff       │ ff          │
└────────────────────────┘
```
