# SHA

RFC 3174（Secure Hash Algorithm）で説明されているとおり、文字列の SHA-1 160-bit チェックサムを計算します。引数が NULL の場合、値は 40 桁の 16 進数文字列または NULL として返されます。

## 構文 {#syntax}

```sql
SHA(<expr>)
```

## エイリアス {#aliases}

- [SHA1](/tidb-cloud-lake/sql/sha.md)

## 例 {#examples}

```sql
SELECT SHA('1234567890'), SHA1('1234567890');

┌─────────────────────────────────────────────────────────────────────────────────────┐
│             sha('1234567890')            │            sha1('1234567890')            │
├──────────────────────────────────────────┼──────────────────────────────────────────┤
│ 01b307acba4f54f55aafc33bb06bbbf6ca803e9a │ 01b307acba4f54f55aafc33bb06bbbf6ca803e9a │
└─────────────────────────────────────────────────────────────────────────────────────┘
```
