# H3_GET_FACES

指定された [H3](https://eng.uber.com/h3/) インデックスが交差するすべての二十面体の面を見つけます。面は 0～19 の整数で表されます。

## 構文 {#syntax}

```sql
H3_GET_FACES(h3)
```

## 例 {#examples}

```sql
SELECT H3_GET_FACES(599119489002373119);

┌──────────────────────────────────┐
│ h3_get_faces(599119489002373119) │
├──────────────────────────────────┤
│ [0,1,2,3,4]                      │
└──────────────────────────────────┘
```
