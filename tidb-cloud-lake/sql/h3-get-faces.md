# H3_GET_FACES

查找与给定 [H3](https://eng.uber.com/h3/) 索引相交的所有二十面体面。面以 0-19 的整数表示。

## 语法 {#syntax}

```sql
H3_GET_FACES(h3)
```

## 示例 {#examples}

```sql
SELECT H3_GET_FACES(599119489002373119);

┌──────────────────────────────────┐
│ h3_get_faces(599119489002373119) │
├──────────────────────────────────┤
│ [0,1,2,3,4]                      │
└──────────────────────────────────┘
```
