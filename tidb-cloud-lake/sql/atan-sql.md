# ATAN2

返回两个变量 `x` 和 `y` 的反正切。它类似于计算 `y` / `x` 的反正切，不同之处在于会使用两个参数的符号来确定结果所在的象限。`ATAN(y, x)` 是 `ATAN2(y, x)` 的同义词。

## 语法 {#syntax}

```sql
ATAN2( <y, x> )
```

## 示例 {#examples}

```sql
SELECT ATAN2(-2, 2);

┌─────────────────────┐
│   atan2((- 2), 2)   │
├─────────────────────┤
│ -0.7853981633974483 │
└─────────────────────┘
```
