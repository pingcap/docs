# ATAN2

2 つの変数 `x` と `y` の逆正接を返します。これは `y` / `x` の逆正接を計算するのと似ていますが、両方の引数の符号を使用して結果の象限を決定する点が異なります。`ATAN(y, x)` は `ATAN2(y, x)` の同義語です。

## 構文 {#syntax}

```sql
ATAN2( <y, x> )
```

## 例 {#examples}

```sql
SELECT ATAN2(-2, 2);

┌─────────────────────┐
│   atan2((- 2), 2)   │
├─────────────────────┤
│ -0.7853981633974483 │
└─────────────────────┘
```
