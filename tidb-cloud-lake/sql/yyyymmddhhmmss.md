# TO_YYYYMMDDHHMMSS

日付または時刻付きの日付（timestamp/datetime）を、年・月・日・時・分・秒を含む UInt64 数値（YYYY *10000000000 + MM* 100000000 + DD *1000000 + hh* 10000 + mm * 100 + ss）に変換します。

## 構文 {#syntax}

```sql
TO_YYYYMMDDHHMMSS(<expr>)
```

## 引数 {#arguments}

| 引数 | 説明 |
|-----------|----------------|
| `<expr>`  | 日付/タイムスタンプ |

## 戻り値の型 {#return-type}

`BIGINT`。`YYYYMMDDhhmmss` 形式で返します。

## 例 {#examples}

```sql
SELECT
  to_yyyymmddhhmmss('2023-11-12 09:38:18.165575');

┌─────────────────────────────────────────────────┐
│ to_yyyymmddhhmmss('2023-11-12 09:38:18.165575') │
├─────────────────────────────────────────────────┤
│                                  20231112000000 │
└─────────────────────────────────────────────────┘

SELECT
  to_yyyymmddhhmmss(to_timestamp('2023-11-12 09:38:18.165575'));

┌───────────────────────────────────────────────────────────────┐
│ to_yyyymmddhhmmss(to_timestamp('2023-11-12 09:38:18.165575')) │
├───────────────────────────────────────────────────────────────┤
│                                                20231112093818 │
└───────────────────────────────────────────────────────────────┘
```
