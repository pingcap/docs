# TO_YYYYMMDDHHMMSS

将日期或带时间的日期（timestamp/datetime）转换为包含年月日时分秒的 UInt64 数字（YYYY *10000000000 + MM* 100000000 + DD *1000000 + hh* 10000 + mm * 100 + ss）。

## 语法 {#syntax}

```sql
TO_YYYYMMDDHHMMSS(<expr>)
```

## 参数 {#arguments}

| 参数 | 描述    |
|-----------|----------------|
| `<expr>`  | 日期/时间戳 |

## 返回类型 {#return-type}

`BIGINT`，以 `YYYYMMDDhhmmss` 格式返回。

## 示例 {#examples}

```sql
SELECT
  to_yyyymmddhhmmss('2023-11-12 09:38:18.165575');

┌─────────────────────────────────────────────────┐
│ to_yyyymmddhhmmss('2023-11-12 09:38:18.165575') │
├─────────────────────────────────────────────────┤
│                                  20231112000000 │
└─────────────────────────────────────────────────┘

SELECT
  to_yyyymmddhhmmss(to_timestamp('2023-11-12 09:38:18.165575'));

┌───────────────────────────────────────────────────────────────┐
│ to_yyyymmddhhmmss(to_timestamp('2023-11-12 09:38:18.165575')) │
├───────────────────────────────────────────────────────────────┤
│                                                20231112093818 │
└───────────────────────────────────────────────────────────────┘
```
