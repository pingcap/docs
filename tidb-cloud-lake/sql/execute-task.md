# EXECUTE TASK

`EXECUTE TASK` ステートメントは、既存のタスクを手動で実行するために使用されます。

**NOTICE:** この機能は、{{{ .lake }}} でのみそのまま利用できます。

## 構文 {#syntax}

```sql
EXECUTE TASK  <name>
```

| パラメータ                        | 説明                                                                                        |
|----------------------------------|------------------------------------------------------------------------------------------------------|
| name                             | タスクの名前です。これは必須フィールドです。                                                       |

## 使用上の注意 {#usage-notes}

- この SQL コマンドで実行できるのは、スタンドアロンのタスク、または DAG 内のルートタスクのみです。子タスクを指定した場合、このコマンドはユーザーエラーを返します。

## 使用例 {#usage-examples}

```sql
EXECUTE TASK  mytask;
```

このコマンドは、`mytask` という名前のタスクを実行します。
