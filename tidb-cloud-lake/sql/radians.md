# RADIANS

引数 `x` を度からラジアンに変換して返します。

## 構文 {#syntax}

```sql
RADIANS( <x> )
```

## 例 {#examples}

```sql
SELECT RADIANS(90);

┌────────────────────┐
│     radians(90)    │
├────────────────────┤
│ 1.5707963267948966 │
└────────────────────┘
```
