# BLAKE3

文字列に対して BLAKE3 256-bit チェックサムを計算します。値は 64 桁の16進数文字列として返され、引数が NULL の場合は NULL が返されます。

## 構文 {#syntax}

```sql
BLAKE3(<expr>)
```

## 例 {#examples}

```sql
SELECT BLAKE3('1234567890');

┌──────────────────────────────────────────────────────────────────┐
│                       blake3('1234567890')                       │
├──────────────────────────────────────────────────────────────────┤
│ d12e417e04494572b561ba2c12c3d7f9e5107c4747e27b9a8a54f8480c63e841 │
└──────────────────────────────────────────────────────────────────┘
```
