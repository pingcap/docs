# H3_IS_VALID

指定された [H3](https://eng.uber.com/h3/) インデックスが有効かどうかを確認します。

## 構文 {#syntax}

```sql
H3_IS_VALID(h3)
```

## 例 {#examples}

```sql
SELECT H3_IS_VALID(644325524701193974);

┌─────────────────────────────────┐
│ h3_is_valid(644325524701193974) │
├─────────────────────────────────┤
│ true                            │
└─────────────────────────────────┘
```
