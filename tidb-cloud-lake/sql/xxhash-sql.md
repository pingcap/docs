# XXHASH64

文字列の xxHash64 64-bit ハッシュ値を計算します。値は UInt64 として返されます。引数が NULL の場合は NULL を返します。

## 構文 {#syntax}

```sql
XXHASH64(expr)
```

## 例 {#examples}

```sql
SELECT XXHASH64('1234567890');

┌────────────────────────┐
│ xxhash64('1234567890') │
├────────────────────────┤
│   12237639266330420150 │
└────────────────────────┘
```
