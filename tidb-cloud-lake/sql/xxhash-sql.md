# XXHASH64

文字列の xxHash64 64-bit ハッシュ値を計算します。引数が NULL の場合、値は UInt64 または NULL として返されます。

## 構文 {#syntax}

```sql
XXHASH64(expr)
```

## 例 {#examples}

```sql
SELECT XXHASH64('1234567890');

┌────────────────────────┐
│ xxhash64('1234567890') │
├────────────────────────┤
│   12237639266330420150 │
└────────────────────────┘
```
