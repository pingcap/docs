# テーブルバージョニング

テーブルバージョニングを使用すると、FUSE テーブルの特定のスナップショットに対する名前付き参照を作成できます。これらの参照は自動保持クリーンアップ後も維持されるため、過去のテーブル状態を指す安定した人間にとって読みやすいポインタを提供します。

> **Note:**
>
> テーブルバージョニングは実験的機能です。使用する前に有効にしてください。
>
> ```sql
> SET enable_experimental_table_ref = 1;
> ```

## スナップショットタグ {#snapshot-tags}

スナップショットタグは、テーブルの特定時点の状態を名前で固定します。タグを作成すると、特定のスナップショットへの参照が保持されるため、スナップショット ID やタイムスタンプを追跡しなくても、[AT](/tidb-cloud-lake/sql/at.md) 句を使用していつでもその正確な状態をクエリできます。

**ユースケース:**

- **リリースチェックポイント**: データパイプラインの実行前後のテーブル状態にタグを付けることで、比較やロールバックを行えます。
- **監査とコンプライアンス**: 保持期限切れを気にすることなく、規制レビュー用に名前付きスナップショットを保持できます。
- **安全な実験**: 現在の状態にタグを付けてから実験的な変換を実行し、その後タグをクエリして何が変わったかを確認できます。
- **再現可能な分析**: データセットのバージョンを固定することで、ダッシュボードやレポートが常に同じデータを参照するようにできます。

**仕組み:**

スナップショットタグは、人間にとって読みやすい名前をスナップショットに関連付けます。タグが存在する限り、参照先のスナップショットは vacuum およびガベージコレクションから保護されます。保持期間が過ぎていても同様です。

- `RETAIN` なしのタグは、明示的に削除されるまで存続します。
- `RETAIN <n> { DAYS | SECONDS }` を指定したタグは、次回の vacuum 操作中に、指定した期間の経過後に自動的に削除されます。

**SQL コマンド:**

| コマンド | 説明 |
|---------|-------------|
| [CREATE SNAPSHOT TAG](/tidb-cloud-lake/sql/create-snapshot-tag.md) | テーブルスナップショットに名前付きタグを作成します |
| [DROP SNAPSHOT TAG](/tidb-cloud-lake/sql/drop-snapshot-tag.md) | スナップショットタグを削除します |
| [FUSE_TAG](/tidb-cloud-lake/sql/fuse-tag.md) | テーブル上のすべてのスナップショットタグを一覧表示します |
