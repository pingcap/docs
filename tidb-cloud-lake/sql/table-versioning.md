# 表版本控制

表版本控制允许你为 FUSE 表的特定快照创建具名引用。这些引用在自动保留清理后仍然存在，从而为历史表状态提供稳定、便于人工识别的指针。

> **Note:**
>
> 表版本控制是一项实验特性。使用前请先启用：
>
> ```sql
> SET enable_experimental_table_ref = 1;
> ```

## 快照标签 {#snapshot-tags}

快照标签通过名称将表在某个特定时间点的状态固定下来。创建后，标签会持有对某个特定快照的引用，因此你可以随时使用 [AT](/tidb-cloud-lake/sql/at.md) 子句查询该精确状态，而无需跟踪快照 ID 或时间戳。

**使用场景：**

- **发布检查点**：在数据流水线运行前后为表状态打标签，以便进行比较或回滚。
- **审计与合规**：为监管审查保留一个具名快照，而无需担心保留时间到期。
- **安全实验**：为当前状态打标签，运行实验性转换，然后查询该标签以验证发生了哪些变化。
- **可复现分析**：固定一个数据集版本，使仪表板和报表始终引用相同的数据。

**工作原理：**

快照标签会将一个便于人工识别的名称附加到某个快照上。只要该标签存在，被引用的快照就会受到 vacuum 和垃圾回收的保护——即使保留时间已经过去也是如此。

- 不带 `RETAIN` 的标签会一直存在，直到被显式删除。
- 带有 `RETAIN <n> { DAYS | SECONDS }` 的标签会在下一次 vacuum 操作期间，于指定时长后自动移除。

**SQL 命令：**

| 命令 | 说明 |
|---------|-------------|
| [CREATE SNAPSHOT TAG](/tidb-cloud-lake/sql/create-snapshot-tag.md) | 在表快照上创建具名标签 |
| [DROP SNAPSHOT TAG](/tidb-cloud-lake/sql/drop-snapshot-tag.md) | 删除快照标签 |
| [FUSE_TAG](/tidb-cloud-lake/sql/fuse-tag.md) | 列出表上的所有快照标签 |
