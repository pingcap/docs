# CRC32

`x` の CRC32 チェックサムを返します。ここで、`x` は文字列であることが想定されており、文字列でない場合も（可能であれば）文字列として扱われます。

## 構文 {#syntax}

```sql
CRC32( '<x>' )
```

## 例 {#examples}

```sql
SELECT CRC32('datalake');

┌───────────────────┐
│ crc32('datalake') │
├───────────────────┤
│        2878859588 │
└───────────────────┘
```
