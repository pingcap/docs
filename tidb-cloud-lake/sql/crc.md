# CRC32

返回 `x` 的 CRC32 校验和，其中 `x` 应为字符串；如果不是，则会在可能的情况下将其视为字符串处理。

## 语法 {#syntax}

```sql
CRC32( '<x>' )
```

## 示例 {#examples}

```sql
SELECT CRC32('datalake');

┌───────────────────┐
│ crc32('datalake') │
├───────────────────┤
│        2878859588 │
└───────────────────┘
```
