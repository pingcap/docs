# COT

`x` のコタンジェントを返します。`x` はラジアンで指定します。

## 構文 {#syntax}

```sql
COT( <x> )
```

## 例 {#examples}

```sql
SELECT COT(12);

┌─────────────────────┐
│       cot(12)       │
├─────────────────────┤
│ -1.5726734063976895 │
└─────────────────────┘
```
