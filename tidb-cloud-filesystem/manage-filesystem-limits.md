# TiDB Cloud Filesystem の使用量制限を管理する

TiDB Cloud Filesystem サービスでは、クレジットカードがなくてもファイルシステムを作成して使用できますが、無料の各ファイルシステムにはより厳しい容量制限があります。これらの制限は、組織にクレジットカードを追加した後に引き上げることができます。

## クレジットカードがない組織の使用量制限 {#usage-limits-for-organizations-without-a-credit-card}

組織に**クレジットカードが登録されていない**場合、無料の各ファイルシステムには次の制限が適用されます。

- リージョンごとに 1 つのファイルシステム
- ファイルシステムごとに 2,000 ファイル
- ファイルシステムごとに 2 GiB のストレージ
- 1 つのファイルあたりの最大サイズは 500 MiB

クレジットカードを追加すると、より高い制限を設定し、従量課金制で引き続き使用できます。課金の詳細については、[TiDB Cloud Filesystem の料金](https://www.pingcap.com/tidb-cloud-filesystem-pricing-details/) を参照してください。

## ファイルシステムの使用量を確認する {#view-file-system-usage}

ファイルシステムの現在の使用量を確認するには、[TiDB Cloud コンソール](https://tidbcloud.com/) でその概要ページに移動し、**Usage** エリアを確認します。使用量の詳細を確認するには、左側のナビゲーションペインで **Usage** をクリックします。

## ファイルシステムが使用量制限に達した場合 {#when-a-file-system-reaches-a-usage-limit}

ファイルシステムがストレージ容量またはファイル数の制限に達すると、既存のファイルは引き続き読み取り可能ですが、そのファイルシステムは新しい書き込みを受け付けなくなります。1 つのファイルは、ファイルサイズ制限を超えて大きくできません。リージョンごとに 1 つのファイルシステムという制限は、そのリージョンで別のファイルシステムを作成するときに適用されます。TiDB Cloud コンソールには警告が表示されます。

## 使用量制限を更新する {#update-the-usage-limits}

1. TiDB Cloud コンソールで [**File Systems**](https://tidbcloud.com/filesystems) ページに移動し、対象のファイルシステムの **Cloud Provider** と **Region** を選択して、そのファイルシステム名をクリックします。
2. ファイルシステムの概要ページで、**Usage** エリアの **Edit Usage Limit** をクリックします。
3. 必要に応じて最大ストレージ、ファイル数、ファイルサイズを設定し、**Save** をクリックします。

    組織にクレジットカードがない場合、これらのフィールドは無効になります。編集して従量課金制を有効にするには、クレジットカードを追加してください。
