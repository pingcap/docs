# TiDB Cloud Filesystem Command Reference

TiDB Cloud CLI (`ti`) provides the command-line interface for working with TiDB Cloud Filesystem. You can use it to create and manage Filesystems, work with files and directories, and use Filesystem features such as Git workspaces, journals, and Vault secrets.

Use this page as an index to TiDB Cloud CLI references related to TiDB Cloud Filesystem. It also includes references for general `ti` commands and behavior that you might need when configuring or updating the CLI.

> **Note:**
>
> This page covers only Filesystem-related command references. TiDB Cloud Starter database commands, such as `ti db`, are documented separately in the [TiDB Cloud CLI documentation](/ai/ti/ti-overview.md).

## General TiDB Cloud CLI references

Use the following references to configure or update `ti` and learn about its general behavior.

## TiDB Cloud Filesystem command groups

Choose a command group based on what you want to do.

- [`ti fs` commands](/ai/ti/reference/ti-filesystem.md) for creating and managing Filesystems and working with Filesystem data.
- [`ti fs-git` commands](/ai/ti/reference/ti-filesystem-git.md) for working with Git repositories and worktrees on a Filesystem.
- [`ti fs-journal` commands](/ai/ti/reference/ti-filesystem-journal.md) for managing Filesystem journals.
- [`ti fs-vault` commands](/ai/ti/reference/ti-filesystem-vault.md) for managing Filesystem Vault secrets.
